# 天壳 · TapTap 成就填报清单（v0.1.4）

> 用途：在 TapTap 开发者后台手动创建 **5 条普通成就**。本目录的 `achv-*.png` 即每条对应的图标。
> 创建完成后，把后台生成的 **成就 ID** 回填到 `src/config.js` 的 `CFG.ACHV` 块（占位值为 `'0'`，回填后自动生效）。

---

## 一、后台操作路径

1. TapTap 开发者中心 → **游戏服务 → 开发与构建 → 成就**。
2. 逐条「创建普通成就」，按下表填 **名称 / 简介 / 图标**。
3. ⛔ 平台要求**至少 5 条普通成就**才能发布 —— 本清单正好 5 条，不多不少。
4. 图标规格：**512×512 PNG**（彩色；平台自动生成灰度未解锁版）。本目录图标已按此规格导出。
5. 全部创建后提交发布。**发布后成就 ID / 分组 / 初始状态全部锁死，不可改、不可删。**

---

## 二、要创建的内容（照抄即可）

| # | 名称 | 成就 ID（后台填这一串） | 简介 | 图标文件 | 类型 | 解锁条件 |
|---|---|---|---|---|---|---|
| 1 | 寒流禁火 | `SHELLBREAK_COLD` | 在禁用保温法的寒流挑战中凿穿天壳 | `achv-cold.png` | 普通成就 | 「寒流禁火」挑战通关 |
| 2 | 小国寡民 | `SHELLBREAK_SMALL` | 在人口上限 15 的挑战中凿穿天壳 | `achv-small.png` | 普通成就 | 「小国寡民」挑战通关 |
| 3 | 忽视科文 | `SHELLBREAK_SCIENCE` | 在学者与书手受限的挑战中抵达最高档并凿穿天壳 | `achv-science.png` | 普通成就 | 「忽视科文」三档全通 |
| 4 | 深渊重压 | `SHELLBREAK_ABYSS` | 在全产出被压低的挑战中抵达最高档并凿穿天壳 | `achv-abyss.png` | 普通成就 | 「深渊重压」三档全通 |
| 5 | 首次轮回 | `SHELLBREAK_FIRST_REBIRTH` | 首次完成一次轮回结算 | `achv-first-rebirth.png` | 普通成就 | 首次合格破壳结算 |

> 说明：
> - 第 1、2 条为**单次挑战**，通关一次即解锁。
> - 第 3、4 条为**三档挑战**，本粒度下**只记最高档**（三档全通才解锁），中间档不单独出成就。
> - 第 5 条与挑战无关，是「第一次轮回」的通用里程碑。
> - 上面名称 / 简介均远短于后台字数上限（后台限：名称 ≤ 40 字、简介 ≤ 200 字、成就 ID ≤ 40 位英文数字），可放心照抄或自行润色。

## 三、创建后回填（交给我）

后台用的 **成就 ID 已按上表锁定并预填好**，无需你回传：

```js
ACHV: {
  cold: 'SHELLBREAK_COLD',                    // 寒流禁火
  small: 'SHELLBREAK_SMALL',                  // 小国寡民
  science: 'SHELLBREAK_SCIENCE',              // 忽视科文
  abyss: 'SHELLBREAK_ABYSS',                  // 深渊重压
  firstRebirth: 'SHELLBREAK_FIRST_REBIRTH'    // 首次轮回
}
```

⚠️ 两边必须**逐字符一致**（大小写敏感）：后台成就 ID 栏填的就是上表那一串。
若后台改用了别的 ID，改这里同名键即可（`'0'` = 未回填，代码自动跳过该条、不请求不报错）。

---

## 四、注意（已知约束）

1. **成就需 TapTap 登录**才有归属：未登录时 `unlockAchievement` 会走失败回调（只记日志，不打断游戏）。当前游戏已接排行榜 + 广告，登录由 TapTap 运行时统一处理。
2. **本地联调**：URL 显式带 `?achvtest` 时走模拟解锁（打 console 日志），不访问平台；与 `?ranktest` / `?adtest` 同一约定。
3. **老玩家宽限**：若某条 ID 尚未回填，玩家即使已达成条件也不会被错记为「已解锁」；回填 ID 后的下一次合格破壳仍会补发。
4. **图标可替换**：`achv-first-rebirth.png` 是程序化生成的占位图（深海青底盘 + 循环箭头），如需更精致的版本可直接覆盖同名文件后重新上传后台。
