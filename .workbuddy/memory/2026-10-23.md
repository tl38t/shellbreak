## 戴森竣工「胜利弹窗离线时不跳」根因 + 修复

- 现象（用户报）：戴森球竣工没跳结算弹窗、也不能点轮回。用户点破关键：**胜利是在离线挂机时达成的**。
- 根因：离线补算 `game.js:966` `SB.economy.tick(j.s, dt, null, {…deferBreakUI:true})` 同步跑完 → 在 `economy-tick.js` 发射场块内 `dysonPct>=1` 时内联调 `showDysonComplete`；但紧接着 `drainCatchUp→finishCatchUp→showOfflineSettlement` 打开**同一 `#modal`**，把胜利窗覆盖；且 `dysonPopupSeen` 在 `tick` 内弹窗前就置 `true` ⇒ 永不重播。
  - `deferBreakUI` 此前在 `economy-tick.js` 只是函数签名、**正文从未消费**（死 flag）；破壳 UI 走 `finishCatchUp` 单独弹，唯独戴森弹窗漏了延迟处理。
  - 在线胜利不受影响（在线 tick 不传 `deferBreakUI`，仍内联弹）。
- 修复（3 文件 + state 种子 + cache-buster）：
  1. `state.js:519` dyson 种子加 `dysonPopupPending:false`（必须进 seed，否则读档静默丢键 + e2e 断言）。
  2. `economy-tick.js` dpsonDone 块：消费 `opts.deferBreakUI` —— 离线时只 `s.dysonPopupPending=true`（**不置 seen**），不内联弹；在线走原 `_R` 分支。
  3. `game.js` 新增 `fireDysonPending(j)`（结算窗关闭后播胜利窗，置 seen + 清 pending，仍按 `s.civics.ascend_void` 走乱码/普通结局）；挂到 `showOfflineSettlement` 的 `onOk`（无 breakReport 分支）与 `modalShown===false` 兜底。破壳与竣工同一段离线互斥，故不与 breakReport 叠加。
  - cache-buster：index.html state.js?v=147→148 / economy-tick.js?v=19→20 / game.js?v=143→144。
- 验证：`sim/probe_dyson_offline_popup.mjs` 7/7 PASS（离线 tick→pending=true/seen=false/done=true；在线 tick→pending=false；旧 bug 对照 seen=false）；`node --check` 三 JS 全过。e2e run5 后台跑（确认无新增回归）。
- ⚠️ 用户当前本机存档：已 `dysonDone=true` 且 `dysonPopupSeen=true`（上轮离线被覆盖时已置位）→ 本局胜利窗不会再弹，但星图戴森面板显示「已竣工」；轮回入口靠 10-21 修的死局（render.js ready 去 `!breakSettled` + game.js askResetRun.onOk 走 nextCycle）已通，可直接点「繁星轮回」。未来离线竣工才会弹窗。
