## 手机端「页面能左右滑动」修复（22:59，用户报）

**根因不在任何页面内容，在头部**：`.header-actions` 是 `flex-wrap:nowrap` 的 flex 容器，
`.brandline` 虽允许换行，但浏览器选择先**压缩** actions（182px）而不是整体换行，
而 actions 内容 min-content 需要 245px（主题切换 182 + 间距 8 + 设置齿轮 56）⇒
齿轮被挤到容器外：`details.ui-settings` rect right=**431**，视口只有 **375** ⇒
`documentElement.scrollWidth=431 > clientWidth=375` ⇒ 整页可横拖。

⚠️ **`body{overflow-x:hidden}` 挡不住**：撑宽的是 `documentElement`，而 html 的 `overflow-x` 是 `visible`。
⚠️ 不能靠给 html 加 `overflow-x:hidden` 遮：那会把齿轮裁成 56px 里只剩 15px 露在屏内，
按钮还在、但半截看不见 —— 症状藏起来、入口废掉（本项目「面板撒谎」家族）。

**修法**（`css/40-atmosphere-theme.css` 的 `@media (max-width:760px)` 块内一行）：
`.header-actions{flex-wrap:wrap;justify-content:flex-end}` ⇒ 齿轮自己在容器内换到第二行、保持右对齐。

**实测（headless Chrome + 390px iframe，`tmp/_probe_panes2.html` / `_probe_widths.html`）**：

| 场景 | 修前 | 修后 |
|---|---|---|
| 390 首屏 | scrollW **431** vs clientW 375（溢出 56） | **375 == 375** |
| 12 个页签逐个点开 | — | **全部 375 == 375** |
| 760 / 1200 桌面 | 正常 | 正常，主题钮与齿轮仍同一行（y 相同） |
| 齿轮位置 | right=431（出屏） | right=367（屏内），弹出层 87..367 也在屏内 |

另核：`talent-map{min-width:1000}` 有 `.talent-map-scroll{overflow-x:auto}` 包着、`.techscroll` 也是 `overflow-x:auto`，
`.tabs` 是 `flex-wrap:wrap` ⇒ 都自吞溢出，不是横向拖动的来源。
