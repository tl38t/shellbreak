## 02 本地 git 仓库重建 + commit&push（用户授权：那就 commit&push）

- **背景**：本地 `.git` 丢失（见 ## 01），远程 `403c3f9`（2026-09-30 19:18）之后的所有工作都没进仓。
- **手法（沙箱坑）**：`git clone` 到工作区外（`/tmp/sbrestore`、`/d/_sb-restore`）**一律被沙箱吞掉**
  —— clone 打印 success 但目录不存在。⇒ 改为在 `D:/shellbreak` 内：
  `git init -b master` → `git remote add origin https://github.com/tl38t/shellbreak` → `git fetch origin`
  → `git update-ref refs/heads/master 403c3f9…` + `git symbolic-ref HEAD refs/heads/master`
  → `git reset`（只动索引，工作树不动）⇒ `git status` 即为「本地比远端多的那部分」。
