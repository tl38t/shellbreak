## 破壳后天穹钻机仍吃 20/秒热液（玩家贴图报障，已修）

**症状**：自然环境卡已改显「破壳后奇观效果 · 市政点 +100/秒；幸福度 +1」，但热液能流面板「去处」

**根因（两处，缺一不可）**：
1. `shell.tickShell` 第一行 `if (s.broken) return 0;` ⇒ 破壳后机器根本不跑，`skydrillOn` 也没人清；
2. `economy.hydroAlloc` 的取流闸**只看** `owned && s.skydrillOn`，不看 broken / shell ⇒
   每 tick 仍按 `SKYDRILL_HYDRO×dt` 把流**真扣走**（后续每一路都是 `left − skyDraw …`）。
   ⇒ 不是显示 bug：白烧 20/秒，下游（钻探/空间站/卫星/发射场）还会因这份被占而欠流降载。

**修法（与 G.E.E.K 那套 `_geekActive` 同构）**：
- `economy.js` 闸补 `&& !s.broken && (s.shell||0) > 0` ——**老存档唯一能救的路**（它们早破壳了，
  靠「破壳那一刻关机」永远等不到）；
- `shell.onShellZero` 里 `s.skydrillOn = false; s.skydrillStarved = false;` —— 新档状态说真话。
- 缓存：`economy.js?v=203` / `shell.js?v=111`。

**判据（`sim/e2e-suites/era4-content.mjs` 新增 4 条，全绿）**：

⚠️ 夹具必须 `s.techs.metalrefine=true`，否则 `RESS.hydro.unlock` 不成立、整个热液面板不建（CDP 踩过）。

## 建筑名可点性：虚线「已经有了但是废的」（用户报「玩家不知道点建筑名能看详情」，先答不改码 → 做 demo）

**结论**：不用加虚线，`.building-name` 本来就有 `border-bottom:1px dotted rgba(105,226,223,.4)`
（`css/30-visual-polish.css:212`）。废掉的原因是 `#pane-village .bzone .row .bld-label .building-name`
那条 `display:block;width:100%;text-align:center`（同文件 :180）—— 边框跟着**盒子**走，
于是虚线从图标右侧一直拉到「等级」标签底下。实测：盒子 340px / 文字 36~48px。
玩家看见的是**行分隔线**，不是链接。奇观页/星图建筑行没这条覆盖（保持 `display:inline`），所以只有聚落页坏。

**demo**：`demo_building_name_affordance.html`（根目录，自包含单文件，深/浅主题 + 390/560/920 三档宽度 +
色差/热区/ⓘ 三个开关 + 点名字出 toast）。四种写法并排：A 现状 / B text-decoration / C 收窄盒子 / D B+ⓘ。

**三种技术路线（都实测过）**
1. **B（推荐）**：`border-bottom` → `text-decoration: underline dotted` + `text-underline-offset:3px`。
   ⚠️ 关键机制：**下划线按 text run 绘制、按盒子绘制的只有 border**。所以只改 1 条声明，
   盒子尺寸与热区一个字没动（实测可点区仍 148/281 随行宽），线自动缩到字底 → 比值 1.00×。
2. **C**：`width:max-content; margin-inline:auto` + `::after{inset:-9px -6px}` 补热区。
   ⚠️ **不能写 `overflow:hidden`** —— 它把 `::after` 一起裁掉，伪元素热区**直接失效**（实测退回 39×20）。
   改布局宽度，风险比 B 大，不建议。
3. **D**：B + 触屏 `ⓘ`（按用户跨项目约定：桌面 `display:none`，`@media(hover:none)` 才出现）。
   每行多占 14px + 8px gap，热区被挤到 126px，视觉更吵，留作后备。

**判据（demo 内部实测，可复跑）**：`elementFromPoint` 从名字中心向四边逐像素扩张量热区。
