✅ 对的部分：`tap.getCloudSaveManager()` / `getFileSystemManager()` / `tap.env.USER_DATA_PATH`；`fs.writeFile({filePath,data,encoding:'utf8'})`；`getArchiveList → res.saves`（顶层字段 `uuid/fileId/name/summary/extra/playtime/saveSize/modifiedTime/createdTime`）；`getArchiveData({archiveUUID,archiveFileId,targetFilePath}) → res.filePath`；`readFile → data`；`createArchive({archiveMetaData:{name,summary,playtime,extra}, archiveFilePath})`。存档名 `shellbreak_main` 无空格无汉字、15 字节 < 60 ✓；summary 非空 ✓；playtime ≥ 0 ✓；extra < 1000B ✓；先 writeFile 后 createArchive 的顺序正确 ✓；`updateArchive` 会改 fileId 而我们每次现查列表、不缓存旧 fileId ✓。
