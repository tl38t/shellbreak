## shellbreak「调整分辨率」实装（仿 EVE-IDLE，本次正主，用户明确授权）
- **机制差异（vs EVE-IDLE）**：shellbreak 是竖向滚动卡片页（`.wrap` max-width:1080 居中、body 滚动），EVE-IDLE 的 `transform:scale()` 定高帧会**破坏滚动**并困住 `position:fixed`（#omen 常驻卡/modal 都在 .wrap 内）⇒ 改用 **CSS `zoom`**：参与布局回流、滚动自然、不创建包含块（fixed 弹窗仍钉视口）。TapTap WebView=Chromium，支持。
- **语义**：档位=设计宽度（720p=1280 / 1080p=1920 / 1440p=2560 / 2K=2048），`scale=innerWidth/设计宽` contain-by-width，钳上限 2.5× 防超宽屏糊；低档=小内部分辨率放大=省 GPU。移动端(touch)/竖屏/auto 恒自然响应式；仅桌面+横屏生效。
- **改动 4 文件**：① `index.html`：ui-settings 弹层加「显示」区 `select[data-ui-resolution]`（5 option）+ main.css ?v 242→243 + theme.js ?v 2→3；② `css/40-atmosphere-theme.css` +2 规则（`.ui-setting-row--select`/`.ui-resolution-select`）；③ `css/main.css`：40 号件 ?v 136→137；④ `src/ui/theme.js`（+61 行）：`RES_KEY='shellbreak.uiResolution'`（localStorage，与 uiTheme/deepBubbles 同模式、不进周目存档）、`currentResolution`/`applyResolution`、boot 初始化 select 值 + change 委托 + resize/orientation 重算。**e2e 安全**：theme.js boot 在 e2e 假 DOM（无 documentElement）早退，新增代码全在 guard 之后。
