## 四、写入纪律

- **进一出一**：往本文件加一条，必须同时外迁一节。**净零增长**，不是「下次记得压缩」。
- **Tier 1 才留下**：能在 5 秒内定位那个 bug 的判据。其余外迁。
- **写入按天批量**，不逐次动笔（用户 2026-09-27 明令）。
- **日志次日 `mv` 进 `archive/`**（单日实测可到 110 KB，占我的上下文）。
- 容量只在**自己动笔前**算一次，且只当内部判据：不为它造命令，不写进回答。
