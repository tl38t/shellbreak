## 九、议价曲线改「真边际效应」＝等比递减（09:00，用户选 60% 档）

**用户两句**：①「改成真边际效益吧，你打算怎么改，上限是多少」②「按照60%的边际效应曲线来吧」。

**先纠正一个认识**：现状上限是 **50% 且是硬到顶**（`HALL_DR_BASE=0.50`，
`hallDiscountLimit` 算下来议事厅/城堡都 =0.50；`HALL_DR_MAX=0.75` 是**死余量**，
全仓只有 `upg_castle` 一个 `hallSaveMul` 来源且它的 0.5 被当基准扣掉）。
所以旧行为是「议事厅 25 级 / 城堡 17 级之后一模一样，再升一分钱不省」。

**数学结论（必须记住）**：「首级 = rate」「每级严格递减」「N 级精确到顶」三者**互斥**。
每级增量 < rate ⇒ N 级累计 < N·rate ⇒ 要达 lim 必须 N ≥ lim/rate；
而严格递减又要求 N > lim/rate。⇒ 只能在「渐近」与「前段线性」之间二选一。
⇒ 选**渐近 + 全程递减**，上限理解为渐近线而非可达值。

**新曲线（`economy.hallEffAt`）**
```
ρ = 1 − rate/lim ;  eff(n) = lim × (1 − ρ^n) ;  每级增量 = rate × ρ^(n−1)
```
`HALL_SAVE 0.02→0.025`、`HALL_DR_BASE 0.50→0.60`、`HALL_DR_MAX 0.75` 不动。
⇒ 议事厅 ρ=0.9583（每 16 级减半）、城堡 ρ=0.9375（每 11 级减半）。

| 等级 | 议事厅 旧→新 | 城堡 旧→新 |
|---|---|---|
| 5 | 10.0% → 11.5% | 15.0% → 16.6% |
| 10 | 20.0% → **20.8%（持平）** | 30.0% → 28.5% |
| 20 | 39.4% → 34.4% | **50.0%（到顶）→ 43.5%** |
| 25 | **50.0%（到顶）** → 39.3% | 50.0% → 48.1% |
| 40 | 50.0% → 49.1% | 50.0% → **55.5%（反超）** |

⇒ 选 60% 档而不是 50% 的目的就在这：**中期小幅削弱、40 级后反超旧上限**，
总强度保留、只是见效推迟（50% 档下 25 级只有 36%，等于硬砍）。
