# Workbuddy 交接：main.css 拆分

## 变更目标

本次只做 CSS 结构拆分，不改变游戏逻辑、数据、DOM 结构或视觉规则。原来的 `css/main.css` 现在是入口文件，负责按原有层叠顺序加载 6 个样式模块。

## 文件结构

```text
css/
├─ main.css                 入口，只负责 @import 和版本号
├─ 00-core.css              基础变量、资源、按钮、基础弹窗
├─ 10-tech-tree.css         科技树、树详情弹窗、奇观详情视觉
├─ 20-panels.css            政体、政策、分区、开关、事件横幅
├─ 30-visual-polish.css     P0/P1/P2 全局视觉基线和通用覆盖
├─ 40-atmosphere-theme.css  氛围背景、日夜主题、主题切换
└─ 50-module-polish.css     导航、工坊、奇观、市政、族民和移动端收尾
```

## 重要约束

1. 6 个模块的加载顺序不能调整。后面的文件包含有意保留的视觉覆盖规则。
2. 修改任意模块后，同时更新 `css/main.css` 内的 `?v=125`，并更新 `index.html` 与 `_shopzone.html` 的 `main.css?v=125`。
3. 不要把响应式规则全部移动到一个新文件；当前部分媒体查询依赖所在模块的层叠位置，贸然集中可能改变样式。
4. 继续美化时，优先在对应模块追加规则；确认稳定后再做重复选择器清理。
