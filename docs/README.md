# 渊海天壳 TIDEBREAK · 深海文明放置

以木卫二（Europa）冰下海洋为舞台的放置 / 挂机游戏。五纪元、44 项科技，主线是科技发展。

**当前进度：P1 竖直切片完成** —— 手动采集 → 建筑 → 人口取舍 → 研究点 → 暗流纪 11 项科技树。

## 运行

双击 `index.html` 即可，不需要构建、不需要本地服务器。
（刻意不用 ES module：`file://` 下会被 CORS 拦死。）

## 工程结构

```
index.html          加载顺序即依赖顺序，不可调换
css/main.css        全部走 CSS 变量，纪元切换只改变量
js/config.js        纯数值层 —— 调平衡只改这里
js/data.js          静态表：资源 / 职业 / 建筑 / 科技
js/state.js         状态 + localStorage 持久化
js/actions.js       所有状态变更的唯一入口
js/render.js        只读渲染（分 fast / full 两类）
js/game.js          主循环 + 事件委托 + 渲染调度
js/main.js          装配
sim/                回归脚本，加载的是真实 src
```

分层铁律：**渲染不得改状态；状态变更只走 `actions.*`。**

## 定稿数值（P1）

| 项 | 值 | 备注 |
|---|---|---|
| 开局 | 人口 1 · 采集者 1 · 资源全空 · 建筑全 0 | 不凭空送产出 |
| 手动采集 | +1 菌毯/次，间隔 ≥120ms | 远超采集者自动产出（0.02/s） |
| 人口增长 | 每 20 秒 +1，上限靠冰窟 | 上限与当前人口是两个量 |
| 学者研究点 | 0.5 / 秒 | 由「暗流纪研究点总量 540」反推 |
| 两极耦合 | 产能 ∝ min(上,下)，开局 10/8 ⇒ 0.8 | 任一侧见底全文明停摆 |
| 菌毯上限 | 基础 100，陶窖/科技追加 | |

**基线（2026-09-25 实测）**

| 策略 | 首建筑 | 全清暗流纪 |
|---|---|---|
| 理性（2 学者 2 壳匠 3 冰窟） | 4s | **756s** |
| 激进（1 学者，全产能） | 4s | 1104s |
| 新手（人全押学者） | 25s | 1046s |

激进流明显慢于理性流，这不是 bug —— 人口零和的取舍确实在起作用。

## 验收命令

改任何数值后，**两个脚本都要重跑**。

```bash
node sim/balance.mjs    # 数值回归：三种策略的时长断言
node sim/e2e.mjs        # 端到端：假 DOM 驱动真实点击路径
```

退出码 0 为通过。

## 科技树（文明6 式节点图）

- **三支三列**：生存（采集 · 战力 · 人口）/ 生计（资源产出 · 上限）/ 求知（研究 · 全局效率）。
- **节点图不是文字列表**：每个科技是一个格位（定宽 154 / 定高 96），纵向按**前置深度**排队；
  前置连线是一层 SVG，坐标与网格同一套算法在 `render.js` 里算好，**不依赖 DOM 测量**
  （所以回归脚本的假 DOM 里也能验证连线）。
- **连线状态**：前置未做成 = 虚线灰；前置已完成 = 实线支色。
- **节点四态**：已完成（✓ 青）/ 可研究（描边发光，可点）/ 条件未满足（暗）/ 未揭示（? 占位）。
- **揭示机制**（对文明6 的"锁定节点"做了替换）：条件不满足的科技显示 `?` 占位，
  **结构可见、内容锁着**；点树顶「全览模式」可临时展开全部（文明6 那样全节点可见）。
- **结绳是唯一免费项**：防止研究资源死锁 —— 玩家永远至少有一项能研究。

## 踩过的坑（改代码前先看）

| 坑 | 症状 | 修法 |
|---|---|---|
| `main.js` 加载期就装配 | 无 DOM 环境下回归脚本直接崩 | 加 `if (!doc) return;` 守卫 |
| `popCap()` 拿 `state.pop` 当底数 | 人口永远长不了，学者一个分不出来，整条科技线卡死 | 上限与当前人口必须是两个量 |
| 批量替换脚本误伤函数体 | `touch()` 无限递归爆栈 | 替换前先确认唯一性 |
| 策略里漏建礁矿 | 壳礁攒着没处花，石工/潮轮永不揭示 | 有成本的资源必须有对应建筑可买 |
| 进度条 CSS 少了 `width` | `--pct` 设了也不显示 | `.bar i` 必须写 `width:calc(var(--pct)*1%)` |
| 布局把同列"根"挤到不同行 | 菌圃没有前置却被压到第二行 | 先算全局前置深度、列内按深度排序后再顺序编号 |
| 回归断言要"所有策略都进区间" | 掩盖了取舍的存在 | 改成"至少一种进区间 + 激进流显著慢于理性流" |
