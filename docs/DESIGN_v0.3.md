## 1. 一句话定位

你带着一批族民被困在天壳之下。**天壳不会自己开**——唯一的出路是科技。
一局里你会遇到一个永远在往前推的取舍：**人就这么多个，是去采集，还是去读书。**
推不动了就重置重开，用上一局的收获走得更快；走到**工业时代**造出**破壳引擎**，撞开天壳看见群星。

| 关键词 | 含义 |
|---|---|
| 第一幕范围 | 溯光 → 蒸汽，共 5 个纪元 **44 项科技**（逐项对标文明6，见 `TECH_TREE_v0.1.md`） |
| 第一幕终点 | 破壳引擎建成 → 冲出天壳 → 通关 |
| 放置手感 | 研究自动推进，玩家不需要每帧操作 |
| 决策密度 | 每几十分钟一次：选下一个研究 / 调职业分配 |
| 软重置 | 周目内没有通关按钮，重置永远是选项 |
| 二期预留 | 信息纪 / 宇宙纪，破壳之后的世界 |

### 核心循环

```
   手动采集（藻食）起步
        ↓
   藻食 → 建藻田（食物自动化，食物线独立循环）
   珊瑚（职业产）→ 建礁口巢 → 人口增长（材料线独立循环）
        ↓
   人口 ← 职业分配（随科技逐个开放）
        ├─ 采集者 → 藻食
        ├─ 珊瑚匠 → 珊瑚
        ├─ 学者   → 研究
        ├─ 后期职业 → 沉铁 / 深渊晶 / 热液能
        └─ 出征军 → 领地（−建筑消耗）← 第三条产出线
        ↓
       科技（暗格 → 揭示 → 花研究点研究）
        ↓  三重收益：解锁 / 效率加成 / 纪元推进
        ↓
   加成回灌研究产出 → 解锁下一段资源与职业
```

**这条循环的支点：人口是零和的。** 分去采集的人不能当学者，当学者的人资源就紧，
派出征的人则 90 秒不产出任何东西且可能阵亡。**三条产出线（建筑 / 科技 / 战争）争同一批人。**

## 2. 五个纪元：一个深海文明的发展历程

不按"水深多少米"分（那是地理，不是文明），按**这个文明处在什么阶段**分。对标文明6 从远古到工业的那 5 个纪元。

| # | 纪元 | 对标 Civ6 | 文明形态 | 这一纪元解决什么 | 收束（仪式） |
|---|---|---|---|---|---|
| 一 | **溯光纪** | 远古 | 穴居在浅礁裂缝里，天光还照得到。骨片、石片、草绳；全族只有一个采集者 | **活下去**：从手动采集到自动产出，第一次出现"记录" | 入海礼 → 珊瑚纪 |
| 二 | **珊瑚纪** | 古典 | 用活珊瑚垒起城礁，驯养发光藻与磷光鱼，出现潮汐历与祭司阶层 | **从部落到城邦**：产出专精、人口规模化、第一次拿到"光" | 城礁典礼 → 沉舰纪 |
| 三 | **沉舰纪** | 中世纪 | 打捞沉在海底的巨舰残骸，第一次得到金属。行会、纹章、冷锻 | **材料革命**：金属让建筑与工具换代，行会做专精分工 | 铁潮礼 → 洋流纪 |
| 四 | **洋流纪** | 文艺复兴 | 读懂洋流，航行到远方海沟，测绘全图，科学方法诞生 | **探索与远征**：走出城礁，研究产出第一次爆发 | 蒸汽先声 → 蒸汽纪 |
| 五 | **蒸汽纪** | 工业 | 在海底热泉上竖起蒸汽机，钢铁壳甲，流水线产能 | **工业化 + 破壳**：把产能推到极限，造出破壳引擎 | **破壳引擎 → 通关** |

加上**独立终局的破壳引擎**（对标 Future Tech 的收尾位置），全树 **44 项**。
**44 项逐个挂到文明6 的具体科技上**，见 `docs/TECH_TREE_v0.1.md`。

**纪元跨越照抄文明6 原规则：完成本纪元全部科技即进入下一纪元。**
上表右列的「入海礼 / 城礁典礼 / 铁潮礼 / 蒸汽先声」是**不占科技位的仪式事件**
（一段文本 + 一次性赠礼），不是科技——否则会破坏 44 项对标，且「洋流图」原名与洋流纪 #1 科技重名。
按纪元重排的完整视图见 `docs/ERA_OVERVIEW_v0.1.md`。

### 2.1 各纪元的"内容"——玩家在这段会见到什么

| 纪元 | 新增资源 | 新增职业 | 新增建筑 | 新增机制 |
|---|---|---|---|---|
| 溯光纪 | 藻食（开局）、珊瑚、研究 | 采集者（开局）、珊瑚匠、藻农、学者 | 藻田、巢窟、珊瑚礁矿、刻纹板 | 手动采集起步、职业分配、科技树开机 |
| 珊瑚纪 | 磷砂 | 育光师 | 珊瑚城礁、育光场、潮汐台 | 照明（深海稀缺品）、城邦加成 |
| 沉舰纪 | 沉铁 | 打捞者、锻工、**出征军** | 打捞场、锻炉、行会厅、**敌巢** | 打捞、行会专精、**战争与领地** |
| 洋流纪 | 深渊晶 | 航海士、测绘师 | 洋流塔、远征港、科学院 | 远征系统、科学方法 |
| 蒸汽纪 | 热液能 | 热泉技师 | 热泉钻塔、蒸汽工厂、**破壳引擎** | 工业化乘区、终局建造 |

### 2.2 为什么要这么分段

文明6 的纪元不是"过了几百年"而是"文明换了套底层逻辑"。深海文明同理：

- **溯光 → 珊瑚**：从"捡到什么吃什么"到"自己种、自己造"——这是农业/定居革命
- **珊瑚 → 沉舰**：从"生物材料"（珊瑚、骨、藻）到"金属材料"——这是材料革命，深海文明拿金属只能靠打捞，天然带叙事
- **沉舰 → 洋流**：从"守着城礁"到"走出去"——这是大航海
- **洋流 → 蒸汽**：从"人力 + 洋流"到"热泉机械"——这是工业革命，也是破壳的唯一途径

每一段换的都是**底层**，不是数值变大。

## 6. 科技树

### 6.1 科技的三重收益

文明6 与猫国的科技都是"买断式"（买完解锁建筑就忘）。我们给每项加第二、三重收益：

1. **解锁** —— 开出建筑 / 职业 / 资源 / 新科技
2. **效率加成** —— 产出乘算，**回灌研究产出**（形成正反馈，这是"科技驱动"的核心）
3. **纪元推进** —— 跨档抬高全局产出

### 6.2 纪元跳档

跨入新纪元 → 全局研究产出 **×1.5**（文明6 是纪元跃迁给一次性奖励 + 全局倍率；数值待标定）。

### 6.3 价格阶梯

直接取文明6 原值，每纪元两档：

| 纪元 | 低档 | 高档 |
|---|---|---|
| 溯光纪 | 25 / 50 | 80 |
| 珊瑚纪 | 120 | 200 |
| 沉舰纪 | 300 | 390 |
| 洋流纪 | 540 | 660 |
| 蒸汽纪 | 805 | 925 |

跨纪元倍率：**×4.80 → ×2.50 → ×1.80 → ×1.49**。
**这是文明6 最重要的一条隐性设计**：价格倍率逐纪元缩小，而玩家产能在同步放大，
所以后期"感觉在加速"。这条必须照抄，不能自己拍。

### 6.4 全部 43 项

见 `docs/TECH_TREE_v0.1.md`：每一项都列出**对应的文明6 原科技**（原名 / 成本 / 前置 / 解锁 / Eureka 原文）、
**我们的科技**（成本 / 解锁 / 揭示条件），以及三处刻意偏离的理由。

溯光纪 11 项（P1 竖直切片的全部内容）：陶泥 / 藻圃 / 礁凿 / 浮筏 / 望壳 / 潮渠 / 骨器 / 结绳 / 石工 / 壳锻 / 潮轮。
其中**陶泥、藻圃、礁凿、结绳 4 项默认可见**（无揭示条件），对应文明6 远古时代开局就有事可做的 4 项。

## 7. 战争与领地（第三条产出线）

对标文明6 的"战争夺取领土"，落点：**打赢 → 领地 +1 → 所有建筑消耗降低**。详见 `WAR_TERRITORY_v0.1.md`。

| 项 | 设计 |
|---|---|
| 领地 territory | 计数，上限 **10**，每块 **建筑消耗 −4%**（线性，10 块封顶 = −40%）＋ 全局产出 +1% |
| 出征 | 派 N 人 + 沉铁 + 藻食，90 秒，确定性判定（出征前给明确预估，不掷骰） |
| 敌方强度 | `20 × 1.35^已占领地数` —— 越往后越难打，天然减速带 |
| 解锁 | **深潜术**（沉舰纪 #3）后发现敌巢：潜得更深，才发现天壳下不止你一族 |
| 自平衡 | **厌战**：每次出征 +1，全局产出 −2%/点（上限 −30%），停战后每 5 分钟消退 |

**它为什么重要**：派出去打仗的人在 90 秒里不产出任何东西，还可能阵亡。
这让"人口零和"从「采集 vs 研究」的二维变成**三维**——每一次出征都是真实取舍。

**减免走线性不走乘性**（踩过猫国的坑）：乘性 −4%/块叠 10 块还剩 66.5%，永远逼近不了 0，
且"显示百分比 / 体感非线性"会骗人。线性 10 块封顶 = −40%，能算到头。

> 军事科技线因此**回归**：骨器 / 壳锻 / 打捞术 / 深潜术 / 舰骨利用 / 压力爆破 / 冲击弹道 / 膛线
> 均带战力或防护收益。**膛线**取代原占位后，**破壳引擎改为独立终局科技**（成本 1200），全树 43 → **44 项**。

## 8. 揭示机制（取代尤里卡）

> 不做"抵扣 50% 研发"。科技默认**暗格**，达成触发条件后**现身，进入可研究队列**。

| 状态 | 含义 | UI |
|---|---|---|
| 未揭示（暗格） | 科技在树上不可见，不显示名字 | 「未知 · 条件：拥有 1 座礁矿」 |
| 已揭示 | 进入可研究对象，需花研究点 | 正常显示 |
| 已完成 | 已付费研究 | 灰显 |

- 揭示**不打折**，只提前可见 → 玩家自己判断这项值不值得先做。
- 揭示条件写在暗格上，玩家看得见"怎么做能让它出来"——**这是把挂机变成"策略性挂机"的关键**。
- 全局约 **10-12 个揭示条件**，每个纪元 2 个左右，避免变成强迫症清单。
- 首次揭示给一次性提示（「潮汐历 已揭示」）。

| | 文明6 尤里卡 | 我们（揭示） |
|---|---|---|
| 效果 | 该科技**立刻完成 50%** | 该科技**现身，需自己研究** |
| 玩家获得 | 白送进度 | 一个**选择** |
| 副作用 | 容易变成被动收账单 | 玩家必须做取舍——值不值花这点研究 |

放置游戏里"白送进度"其实削弱决策，所以只借它的**条件设计**，不借它的**效果**。

## 9. 重置与破壳

用户已明确：第一周目可以推到工业时代打破天壳，但要花很长时间；正常玩不会等到那儿，推不动了就重置重开。

| | 软重置（默认路径） | 硬通关（第一幕终点） |
|---|---|---|
| 触发 | 玩家自己判断"推不动了" | 造出破壳引擎 |
| 时机 | 随时，可反复 | 全局只此一次 |
| 收益 | 重置货币（买增益） | 冲出天壳、望见群星 |

### 软重置

- **保留**：科技记录（已揭示 + 已完成）、重置货币、统计、已抵达的最高纪元
- **清空**：资源、人口、建筑、职业分配
- **收益锚定**（三项，主次分明）：
  1. 抵达最高纪元（主项，跨档斜率递增）
  2. 已完成科技数
  3. 峰值人口（副项）
- **"该重置了"的信号**：研究产出**增速**掉到阈值以下时 UI 给软提示；结算面板常驻显示「现在重置可得 X 点」。

> 重置收益必须是乘区。加法的话重开一局只是"从头再来 + 一点点"，不足以补偿损失，玩家不会重置。

### 破壳（第一幕终点）

蒸汽纪最后一项 **破壳引擎** 建成 → 天壳裂开 → 望见群星 → 第一幕通关。
破壳后产出**星屑**，作为二期（信息纪 / 宇宙纪）的接入口径。

## 10. 二期预留：信息纪 / 宇宙纪

**本期只做到工业时代破壳。** 以下两段留白，但接口先定好：

| 纪元 | 对标 Civ6 | 设想（不落地） | 接口 |
|---|---|---|---|
| 六 · 信息纪 | 信息 / 原子 | 破壳后看见群星，却发现天壳之外还有壳；生物计算、共生神经网、灵脉通讯 | 消耗星屑；继承第一幕已完成的科技记录 |
| 七 · 宇宙纪 | 未来 | 星海航行、殖民其他海洋星球 | 信息纪的收束科技 |

定死的接口只有一条：**破壳引擎产出星屑，星屑是二期的唯一入口货币**。
这样二期加纪元时不需要改动第一幕的任何数值。

## 11. 开局第一步（可玩定义）

| 步骤 | 内容 |
|---|---|
| 1 | 1 名族民，**职业只有采集者**，资源有**藻食**和**珊瑚**两条 |
| 2 | 手动点「采集」+1 藻食（0 采集者也能点，对齐猫国点森林） |
| 3 | 攒 15 藻食建第一座**藻田** → 藻食开始自动产出（食物线自动化） |
| 4 | 同一名族民转**珊瑚匠**，攒 10 珊瑚建第一座**礁口巢** → 人口开始自然增长 |
| 5 | **结绳**随第一座巢窟揭示 → 学者职业与研究资源上线 |
| 6 | 研究点开始积累 → 科技树正式开机，溯光纪剩余 9 项展开 |

**验收标准**：从开局到能自动运转（第一座藻田建成后不需要玩家干预），**不超过 60 秒**。旧项目这一段要 277 秒且全程空转。
