# 海底文明 lens：科技树复用过滤器

> 建立于 2026-09-25。作用：所有「从猫国建设者 / 文明6 抄机制」的动作，先过这三条过滤器，
> 再决定抄不抄、抄机制还是抄名字。
> 背景文档：`docs/DESIGN_v0.3.md`（玩法基线）、`sim/e2e.mjs` 里的回归锁。

---

## 一、三条铁律

1. **机制照抄，名字不照抄。** 猫国 / Civ6 的科技名与建筑名是陆地文明（谷物、家畜、城墙、陶土、船），
   直接搬进来会在世界观上穿帮。抄的是**结构**（谁解锁谁、奖励是什么形状），命名一律用我方词表
   （菌毯 / 珊瑚 / 矿砂 / 骨材 / 精铁 / 科技 / 地热）。
2. **「没有对应物」不等于缺口，先判断是缺一条线，还是这根本不需要。** 猫国 / Civ6 里有、
   而我们世界观里不该有的东西（航海、宗教圣地、家畜畜牧），不要为了「对齐 11 项」硬补。
3. **信息型奖励优先保留。** 科技开页签 / 开预测面板这一类（猫国 calendar→时间页签、math→统计页签）
   是 rewrite 时最容易被漏掉、但对「我感到在推进」贡献最大的一类。抄什么都别抄掉它。

Civ6 标准版远古 **11 项**（累计 565 ），猫国「science ≤1500」**15 项 = 10 科技 + 5 政策**。
海底 lens 下，上次报告里那两条「缺口」需要改判：

| 畜牧 Animal Husbandry 25 → 牧场 | 驯兽 500 → pasture | `观潮` 50（food +0.15） | ✅ **改判：不是「畜牧」是「占星位」** |

| **占星 Astrology** → 圣地 | — | `观潮` 50 已覆盖其「观测→奖励」 | ✅ 拆掉宗教外壳，保留观测内核 |

### 两条改判的说明

**航海 Sailing —— 从「缺口」改为「不抄」。**
Sailing 在 Civ6 里解锁的是「造船 → 海外单位 → 海外殖民地」，驱动力是**陆地文明必须跨海扩张**。
海底文明整体处于水下，没有「渡海」这一步；我方探索需求已由星图 / 虫洞那条线承担。
⇒ 不要建「航行」科技，但要保留它的**结构**：解锁一个全新的可进入区域。

**占星 Astrology —— 从「缺口」改为「已覆盖」。**
Astrology 的原始产出是圣地（宗教建筑线），海底世界观用不上；但它的真实设计内核是
「观测天象 → 获得别人没有的信息（预测）」，我方 `观潮`(50) + `历法`(60) 已经用潮位 / 季节把这条内核接住了。
⇒ 不需要补一条宗教线，只需要保证「观测类科技确实给了信息型奖励」——见铁律 3。

> 结论：海底 lens 下，远古 11 项对应我方 **9~10 项**，缺口为 **0**。上一版报告里
> 「补航海 / 占星两条线」的建议作废。

## 四、命名清理（已于 2026-09-25 完成）

| 位置 | 原名 | 新名 | 理由 |
|---|---|---|---|
| `hearthfire` | 取暖术 | **保温术** | 「火」= 陆地取火语境；改靠热泉蓄热解释 |
| `hearth` | 取暖石 | **暖壳石** | 同上 |
| `furnace` | 熔炉 | **热泉炉** | 火源改挂地热，不是木炭 |
| `blastfurn` | 鼓风炉 | **烟囱炉** | 「鼓风」需要风，水下不成立；热泉烟囱自带抽力 |
| `keel` | 龙骨 | **壳骨** | 龙骨是船体部件，本作是壳体工程 |

配套清理：`src/techs.js` / `src/economy.js` / `src/shell.js` / `sim/balance.mjs` / `sim/e2e.mjs` 里的
旧名注释，以及所有 `note: 'Civ6: …'` 改成 `note: '机制同源：X，命名不照抄'`。

⚠️ **只动 `name`（显示名），不动 `id`** —— `hearth` / `furnace` / `keel` 这些 id 被
`state.js` / `economy.js` 直接引用，改名不会触发 migrate，也不触发标定债。

| 优先级 | 动作 | 现状 | 性质 |
