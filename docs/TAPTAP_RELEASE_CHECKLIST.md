## 一、⚠️ 三个决定性发现（推翻先前的假设）

### 1. 天壳走「快速上架」⇒ **不需要版号**

官方原文（小游戏创建页）：
> 「**不涉及内购功能的小游戏无需提交版号**，普通小游戏在正式上架前需完成**小游戏前置备案**」

天壳是**零内购**（只有激励广告）⇒ **版号这一关过了**。
仍需**小游戏前置备案**（不是版号，是备案，流程轻得多）。

### 2. 包体上限：首包 ≤ 60MB（不是我以为的 20MB）

- 小游戏创建页：「**首包大小不超过 60M+**」
- 审核规范 5.2.2：「小游戏包体大小限制为 **20MB 以下**」
- ⇒ **两处口径冲突，按最严的 20MB 规划**。当前 19MB，**已经在临界线上**。

### 3. 防沉迷：零内购小游戏**平台默认代管**

> 「游玩方式仅有『小游戏』的情况下，防沉迷系统**默认依托平台开启，开发者无需额外操作**」

⇒ 不用自己做实名系统。天壳无内购 ⇒ 满足条件。

## 三、创建游戏需要哪些准备（官方物料清单）

### 3.1 必填物料（`*` 标记）

| # | 物料 | 规格 | 天壳现状 |
|---|---|---|---|
| 1 | **图标** | ≥512×512px（1:1），png/jpg，**直���方图不要自己切圆角**，不得白底/黑底/透明底/默认图标 | ❌ 无 |
| 2 | **简介** | 描述类型/玩法/特色，**不得填联系方式、兑换码、群信息、外部链接**。建议主文控制在**前 50 字** | ❌ 待写 |
| 3 | **更新日志** | 首次提交**不要填**（会误导玩家） | ✅ 跳过 |
| 4 | **游戏截图** | ≥3 张，**方向与宽高比必须全部一致**且与第一张一致。横版 ≥1280×720（宽高比 8:3~8:5）／竖版 ≥720×1280（宽高比 3:8~5:8）。png/jpg，**单张 ≤4MB，建议 ≤1MB**。**实机画面 ≥50%**，概念图/宣传图**至多 2 张**且实机截图必须排最前| ❌ 待截 |
| 5 | **实机录屏**（下载/试玩必填） | MP4/MOV，H.264/HEVC，≤5GB，**>15 秒**（建议 2 分钟内，上限 30 分钟），**短边 ≥540px**，宽高比 21:9~9:21 | ❌ 待录 |
| 6 | **宣传图 16:9** | ≥1920×1080，png/jpg，≤4MB。**必须显示游戏名，且除游戏名外不得有其他文字**；不得出现游戏图标、不得直接用游戏截图、不得有实物手机 | ❌ 待做 |

### 3.2 录屏硬规范（写得很细，容易被打回）

- **前 5 秒内**就要出现核心玩法，且核心玩法**连续展示 >10 秒**
- 前 30 秒内不得有超过 10 秒的纯 CG/立绘/过场动画
- **不得**添加游戏本体外的配音和字幕（可剪辑加速）
- **不得**有前贴片；后贴片只能有厂商 logo 和游戏 logo
- **不得**出现其他平台 logo 水印 / 第三方导流
- **不得**用圣光、暗幕、云团、表情包、马赛克遮挡
- **不得**画中画，**录屏画面占比 ≥80%**
- **不得**拍出游玩设备（不要拍手机/显示器）
- **不得**展示纯商业化内容（折扣、充值）

### 3.3 截图易踩雷点

- 禁止出现**手机 UI**、禁止重复单一截图
- 禁止只展示卡片/立绘/Loading/主界面来掩盖真实玩法
- 禁止在截图里加**虚假下载按钮、分享按钮**或模拟交互元素
- 禁止加水印、时间戳
- 禁止翻转/颠倒/旋转图片

### 3.4 「快速上架」额外要求（聚光灯教程）

- 上架方式选**「快速上架」**
- **适龄分级**照游戏内容选（8/12/16+），**别一律选最低**
- 《创意工坊内容授权协议》**开发商和发行商两个都要勾**
- **两步不能漏**：① 商店→游戏包管理→小游戏管理→上传 H5 zip 包体，填一个比线上大的版本号
  ② 回到资料页「游戏下载和获取→H5 小游戏」→**选中刚上传的那个包体**
- 游戏发布状态分端设置，你打算发布的端都要设成「**提供游玩**」

### 3.5 与广告相关的审核条款（天壳加了广告，必须守）

| 条 | 内容 |
|---|---|
| 1.3.1 | **不得存在空白广告位**或主要目的为展示广告 |
| 1.3.2 | 广告不得模仿系统通知诱导点击 |
| 1.3.7 | 广告信息需**显著标明「广告」** |
| 1.3.10 | Banner 高度 ≤屏幕 10%，不遮挡操作按钮，须有明显关闭按钮 |
| **1.3.12** | **激励广告不得以虚假奖励诱导点击**（奖励需与实际一致） |
| 1.3.13 | 激励广告播放期间**需允许随时关闭**，关闭后能正常返回游戏 |
| 1.3.14 | 插屏广告仅允许在自然断点触发 |

⇒ 天壳的「看广告 +30min 2×」是**激励广告**，`isEnded` 才发奖、中途退出不发
⇒ 符合 1.3.12/1.3.13。**但按钮上应出现「广告」二字**（1.3.7），当前文案是
「看广告 +30min 2×」已含「广告」✅。

## 四、发布流程（官方顺序）

1. 开发者中心 → 创建游戏 → 填基础信息（名称、类型）→ 保存提交
2. 获得**游戏 ID**，此时状态「未发布」，玩家搜不到
3. 点游戏图标/标题进管理面板 → 商店 → 商店资料 → 完善详情 → 下一步提交审核
4. （正式上线试玩版还需）游戏包管理 → 小游戏管理 → **小游戏资质**（防沉迷+前置备案）
5. 游戏包管理 → 小游戏管理 → 包体管理 → **上传包体**（zip），版本号格式 `V x.y.z`（整数，新版必须高于旧版且唯一）
6. 回资料页选中该包体 → 发布状态设「提供游玩」→ 提交审核

### 时效

| 事项 | 官方时长 |
|---|---|
| 首次提交审核 | **1-3 日**（资料合规情况下） |
| 更新版本审核 | 约 **1 日** |
| 首次设置定时上线 | 时间须设在当前**6 小时后** |
