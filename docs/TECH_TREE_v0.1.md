## 1. 总览：文明6 到工业时代共 43 项，我们一对一映射

文明6 从远古到工业（不含现代/原子/信息/未来）**合计 43 项**。我们照抄这个分布，不做"每纪元 10 项"的人为均分。

| 纪元 | 对标 Civ6 | Civ6 项数 | 我们项数 | Civ6 成本档 |
|---|---|---|---|---|
| 一 · 溯光纪 | Ancient 远古 | 11 | **11** | 25 / 50 / 80 |
| 二 · 珊瑚纪 | Classical 古典 | 8 | **8** | 120 / 200 |
| 三 · 沉舰纪 | Medieval 中古 | 7 | **7** | 300 / 390 |
| 四 · 洋流纪 | Renaissance 文艺复兴 | 9 | **9** | 540 / 660 |
| 五 · 蒸汽纪 | Industrial 工业 | 8 | **9**（含额外终局破壳引擎） | 805 / 925 / 1200 |
| **合计** | | **43** | **44** | |

成本阶梯**直接取文明6 原值**，跨纪元倍率：

```
25 → 120  ×4.80
120 → 300 ×2.50
300 → 540 ×1.80
540 → 805 ×1.49
```

**这是文明6 最重要的一条隐性设计**：时代越往后，价格倍率越小（×4.8 一路降到 ×1.49），
但玩家的研究产能在同步放大——所以后期"感觉在加速"，而不是"感觉在爬坡"。这条必须抄，不能自己拍。

同纪元内分两档（如远古 25/50/80），也是文明6 的原结构，不是我们发明的。

### 本纪元的节奏（抄文明6 的原设计）

文明6 远古时代的 11 项里，**只有 4 项有 Eureka**（Sailing / Astrology / Irrigation / Archery / Masonry / Bronze / Wheel 有，Pottery / AH / Mining / Writing 里 Writing 有）。
这些"无条件可研究"的项就是开局的可选动作——玩家开局马上就有事做，不用等触发。

我们照抄：**11 项里有 4 项不需要揭示条件（默认可见）**：陶泥、藻圃、礁凿、结绳。
开局玩家立刻能选"先搞储存、先搞农业、先搞材料、还是先搞记录"。

## 7. 三处刻意偏离文明6 的地方

| # | 偏离 | 原因 |
|---|---|---|
| 1 | **结绳免费**（揭示即完成，不花研究点） | 文明6 开局就有科研产出，我们没有——研究资源要到结绳才上线。若结绳也要花研究点会死锁。对应地，文明6 的 Writing 有 Eureka（遇见文明），我们改成"建成第一座巢窟"揭示 + 免费完成，作为教学赠礼。**这是唯一一项不花研究点的科技。** |
| 2 | **Eureka → 揭示，不抵扣** | 已拍板。只借文明6 的条件设计，不借 50% 抵扣效果：放置游戏白送进度会削弱决策。 |
| 3 | **战争线：不删，改造**（2026-09-25 修订） | 原本我把 Archery / Bronze / Iron Working / Gunpowder / Ballistics / Rifling 整条军事线删掉了。现在**恢复**：这些科技回到军事本行（战力 / 防护 / 阵亡率），见 `WAR_TERRITORY_v0.1.md` 第 8 节。战争成为第三条产出线（抢领地 → 降低建筑消耗），与人口零和直接耦合。 |

## 8. 待定

- 成本是否直接用文明6 原值（25→925），还是整体缩放（P1 标定研究产出后决定）
- 同纪元内两档的划分依据（文明6 是"该科技在树上的深度"，我们暂按序号前后半分）
- 揭示条件的**具体数值**（人口 3 / 建筑 4 / 打捞 3 次等需 P1 实测调）
- 文明6 的"科技强化"（如 Education 让大学 +1 科研）我们没有直接对应物，暂用效率加成替代
- 是否做文明6 的"过时/淘汰"机制（新科技让旧建筑失效）—— 暂定不做，放置游戏里淘汰会让玩家有损失感
