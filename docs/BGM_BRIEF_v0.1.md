# 这是个什么游戏 · 兼配乐需求

> 给作曲的朋友，也给他要喂的 AI。
> 目标：让一个完全没玩过、甚至没听过这项目的东西，读完知道这是个什么游戏、玩家在里面干什么、音乐要在什么时候响多久。
> 前面全是"游戏是什么"，音乐需求在 §5 之后。嫌啰嗦可以直接跳。

---

## 0. 三句话版本

**《自海渊至群星：深海文明建设》**。一款手机上的放置（idle / incremental）游戏，一个人做的，正在 TapTap 上测试。

**故事**：木星卫星欧罗巴的冰层下面有一片海洋，海洋里有一个文明。他们头顶没有天空，只有 15 公里厚的冰。玩家从"1 个人、一个采集者"开始，把这个文明做到能凿穿那层冰，然后抬头看见木星。

**两首曲子**：破壳之前的，和破壳之后的。

---

## 1. 玩家到底在干什么（这条最重要，AI 几乎一定会搞错）

这不是动作游戏，不是 RPG，屏幕上没有角色在跑、没有场景在滚。屏幕上是一大片数字、按钮和进度条，深蓝底，粗糙的矢量图。

它的玩法是**猫国建设者 / 饼干点点乐 / Factorio 挂机版**那一类——用中文说就是"放置类"：

| 玩家做的事 | 占一局的时间 |
|---|---|
| 把手机放着，让游戏自己跑，数字自己涨 | **绝大部分** |
| 偶尔回来点几下：造一座建筑、把 3 个人从采集调到研究、点个科技 | 累计可能只有 20 分钟 |
| 冬天来了调人去烧地热、盯着资源条别饿死 | 少数几次真的紧张 |

**一局 8 到 14 小时。** 玩家真正"在玩"的时间大约 20 分钟，其余时间他在吃饭、上班、睡觉、上课，手机搁在桌上或者口袋里，游戏在后面跑。

这件事对音乐的含义，比任何风格描述都重要：

> **同一首曲子，玩家会听几百遍。而且他不在听。**

所以：
- **不能有"段落"**。不能有"第二乐章开始了"，不能有"高潮"，不能有"要来了要来了"。玩家听第 40 遍的时候，任何叙事结构都会变成噪音。
- **不能抢注意力**。玩家低头看手机那一刻，脑子里想的是"精铁够不够"，不是"这段旋律真美"。
- **它其实是环境音，不是配乐**。是那个房间的天气。玩家不该记得它，但关掉会觉得空。

**这是这类游戏配乐最难的地方，也是唯一真正的考点。** 做一段好听的音乐不难，做一段"能陪着人熬四小时还不烦"的音乐很难。

## 2. 世界设定

### 2.1 舞台

不是地球深海，是**木星的卫星欧罗巴（木卫二）**。真实天体，真实数据。

```
      冰  壳（15–25 km）    ← 头顶的"天"。会响，会裂，会呻吟
   ═══════════════════════
      海  洋（60–150 km）   ← 文明活在这层。地球全部海洋的 2–3 倍
   _______________________
      岩  石  海  底        ← 比马里亚纳海沟还深（约 135 MPa）
```

表面 −160 °C，没有空气，木星辐射打在上面是致命的（数 Sv/天，几分钟就死）。

### 2.2 四条会改变声音的怪事

**① 他们没有太阳。**
"天"就是那面冰，抬头是天花板。而且是**会响的天花板**——现实里的冰架（南极那种）会以 0.5–10 Hz 的整体共振"唱歌"，人耳听不全，胸腔能感觉到。

**② 他们没有火。**
火要三样：氧气、燃料、点燃温度。这里一样都不成立。所以这个文明的第一把火是**电**——第一次让电子走外电路。人类从火开始，他们从电开始。

**③ 他们活在一节电池里。**
能量不来自阳光，来自上下两极的化学势差：
- **上面**：木星辐射把冰壳表面的水打成氧，渗下来；
- **下面**：海水和海底岩石反应，放出氢。

氧化剂在上，还原剂在下，中间隔着一百公里海水。**整个文明活在这个电势差里。** 这也成了游戏最核心的机制——产能等于两边取小，一边短了整个文明熄火。

**④ 杀死他们的东西，就是养活他们的东西。**
那辐射对表面是死刑，但正是它造出了深海里所有的食物。**凶手和母亲是同一个。** 这是整部作品情感重量的来源——不是"我们赢了"，是"我们终于敢看了"。

### 2.3 他们是谁

**鲛人。** 不是童话里的人鱼，是深海里的劳动者：采集者、菌农、壳匠、学者、采氧人、采硫人、深潜者、潮汐技师。

他们的语言里没有"太阳"这个词，也没有"地平线"这个概念，因为从没见过。他们的"世界有多大"是靠**听**出来的：水里能见度几十米，声音能传几公里。

**规模感很重要**：开局整族 1 个人。一局峰值也就几十个人。这不是"文明史诗"，是**一户人家在黑暗里点了一盏灯**。

## 3. 一局是怎么走的（两半）

游戏有十个纪元，五个在壳里，五个在壳外。破壳就是那条分界线。

| | 壳内 | 壳外 |
|---|---|---|
| 纪元 | 暗流 → 冷焰 → 硫泉 → 洋流 → 破壳 | 初生 → 繁星 → 探索 → 寻光 → 驭星 |
| 玩家在干什么 | 捞东西吃 → 农耕定居 → 挖金属 → 远征全海 → 工业化 | 出壳 → 造火箭 → 星海工业 → 恒星工程 → 戴森球 |
| 时间 | 3–4 小时 | 3–4 小时 |
| 一句话 | 还不知道天是什么 | 第一次有了"上" |

**注意：破壳不是通关，是转折。** 破壳之后还有一整套星海线要玩，又是三四个小时，一直到文明大到能包住一颗恒星。

**而且这游戏会反复循环。** 破壳之后可以"轮回"——带着积累的加成重开一个新周目，冰壳更薄，走得更快。所以玩家会**反复听到这两首**，不是听一次。

## 4. 破壳那一刻（全程唯一一次"演出"）

九个多小时里，只有这一刻有画面序列。四帧，总共 4.9 秒：

| 秒 | 画面 | 字幕 |
|---|---|---|
| 0 | 钻机在海底蓄力，整座城市为它供能 | 「共振，启动。」 |
| 1.5 | 钻头触壳，裂纹沿着冰层亮起来 | 「钻头触壳。」 |
| 3.2 | 鲛人游向钻机，仰望裂开的天 | 「裂痕，扩散。」 |
| 4.9 | 天壳打开，钻机和鲛人一起抬头 | 「天壳之外。」 |

然后进结算面板，告诉玩家这局攒了多少，可以开始下一轮。

**但玩家等这一刻等了三四个小时。** 他看的不是 5 秒，他是在"到达"。

抬头看见的东西：**木星，占满四分之一天空**，角直径 11.89°，是地球满月的 22.9 倍、面积的 523 倍。它有纹路，在缓慢转动，**不闪**——他们从没见过不闪的星星。外面还有肉眼可见的辐射辉光，就是那个杀了他们祖先几百万年的东西，在发光。

## 5. 所以两首曲子分别是什么

前面那些设定，全部是为了这两句话：

> **第一首：「我们还不知道天是什么。」**
> **第二首：「我们第一次有了上。」**

| | 曲一《壳内》 | 曲二《壳外》 |
|---|---|---|
| 什么时候响 | 一局前半程，3–4 小时，反复循环 | 破壳演出 + 后半程 3–4 小时，反复循环 |
| 玩家在干什么 | 挂着，偶尔回来点两下 | 同上。前 5 秒在看破壳演出 |
| 世界 | 有天花板，声音被水吸收，闷、近、干 | 没有天花板。真空，巨大，有延迟和回声 |
| 规模感 | 一户人家的灯 | 一个人站在太大的东西下面 |
| 情绪 | 忍耐。不悲伤，也绝不轻松 | 失重 + 敬畏 + 一点恐惧。**不是胜利** |
| 绝对不能是 | 海洋纪录片 / 史诗预告片 / 紧张 | 英雄凯旋 / 太空歌剧 / 宏大 |

**关键差异不在"大小"，在"有没有上方"。** 曲一是水平的——所有声音在同一个高度上铺开，像水；曲二第一次有了垂直，声音往上走，落不下来。

## 6. 给 AI 的两段提示词（可以原样粘）

**曲一 · 壳内**

```
Background music for an idle game set in an ocean beneath 20 kilometres of ice on
Jupiter's moon Europa. Ambient, not soundtrack. No percussion. No pulse, or a pulse
as slow as breathing and only occasional. A deep sub-bass drone that feels like an
ice ceiling resonating at 0.5-10 Hz — you feel it more than hear it. Dry close-miked
cello harmonics, bow scraping rather than vibrato. Glass harmonica, rubbed metal,
a dirty old church organ at low pitch. Field recordings made literally underwater:
muffled, high frequencies absorbed, no reverb tail. D Dorian, no complete major triad
anywhere. Sparse distant unintelligible human breath. Emotional register: patience,
not sadness. It should sound like a place, not like a piece of music. It must loop
seamlessly for hours without the listener noticing structure. 4 minutes.
```

**曲二 · 壳外**

```
Background music for the second half of the same game, after the civilisation has
broken through 20 kilometres of ice and seen open sky for the first time. Wordless
choir breathing together, no language. Very close internal sounds — heartbeat, blood,
breath heard from inside the head — bone conduction. Around them an enormous delayed
space: long pre-delay, echoes returning transformed. Horns far away and held back,
never bright, never heroic. Cold tubular bells. Strings finally allowed to sustain.
Keep some grit: ice cracks, metal friction, ugly welds. D Lydian, the sharp fourth
left unresolved so it never lands. One complete major triad appears exactly once and
is left hanging. Emotional register: weightlessness and awe, not triumph. 3 minutes,
seamless loop, and the first 40 seconds must also work alone as a cue for a 5-second
cinematic transition.
```

## 7. AI 一定会搞错的六件事（负面清单，这条比提示词有用）

AI 音乐模型对"太空""深海""史诗"有极强的套路记忆，会往下面这些方向跑。**这些全是错的：**

| AI 会给的 | 为什么错 |
|---|---|
| 《星际穿越》式管风琴 | 太有名，一听就出戏。玩家会想"哦，星际穿越" |
| BBC 海洋纪录片那种鲸歌、水泡、海浪 | 他们不是鲸，也不在水面，而是在 100 公里深的水下。而且太"自然纪录片" |
| 史诗太空歌剧：大鼓、铜管齐鸣、拉丁文合唱 | 这是一个几十人的文明，不是帝国。而且他们还没有"英雄"这个概念 |
| 紧张感：弦乐 ostinato、ticking 时钟、低频震颤 | 这里没有敌人。玩家的紧张是"精铁不够"，不是"有东西要来" |
| 明亮的大调、上扬的解决、胜利终止式 | 全程只允许一次大三和弦，在曲二末段，而且不许解决 |
| 明显的前后段落、渐强、drop | 玩家要听几百遍。任何"结构"在第 40 遍都会变成噪音 |

**判断标准很朴素**：如果它让你想起某部具体的电影，就是错的。它应该让你想起某个地方。

## 8. 工程规格

| 项 | 曲一 | 曲二 |
|---|---|---|
| 时长 | ≥ 4:00，**无缝循环** | ≥ 3:00 循环；前 40 秒要能单独当破壳演出用 |
| 采样率 | 44.1 kHz | 同 |
| 交付 | WAV 母版 + MP3 320 备份 | 同 |
| 建议成品码率 | 128 kbps MP3 或 96 kbps OGG | 同 |
| 单曲大小 | ≤ 4 MB | ≤ 4 MB |
| 响度 | −18 LUFS 左右，**动态范围要窄** | −16 LUFS，动态范围要宽 |
| 峰值 | ≤ −1 dBTP | ≤ −1 dBTP |
| 循环点 | 给"首尾能直接接上"的版本，并在时间码上标 loop 点 | 同 |

**为什么卡这么死**：整个游戏包现在 18 MB，两首各 4 MB 会推到 26 MB，对 TapTap 小游戏偏大了。所以码率不能高，时长也不建议超 5 分钟。两首之间有共用素材的话，复用能省不少。

**另外**：游戏现在**完全没有音频代码**——没有 BGM 系统、没有音量设置、没有静音开关。这些我这边做，不用管。但如果你能给分轨（至少把低频单独留一轨），我调起来会舒服很多，因为玩家可能在通勤路上外放，低频一多就糊。

## 9. 如果你想要一个统一的结构（可选，不是要求）

两首各自成立也能用。但如果你想让它俩听起来是"同一个世界"，有个做法我觉得很值：

**一个三到五个音的动机，两首共用。**

- 曲一里它反复出现，但**永远差一个音**——或者被低音盖住一半，或者在混响里散掉。玩家会不知不觉记住它，但说不出。这是"文明还没长成"的声音形态。
- 破壳那一刻，它**第一次完整出现**，单声部、无伴奏、没有混响尾巴。全作唯一一次干净的声音。
- 曲二最后 30 秒，它回来，完整、上行，而且**第一次有回声**。

最后这条是我最想要的：**冰下没有回声**（声音被水吃掉了，喊出去就没了），**壳外有回声**（因为外面太空了）。这一下就是整个游戏的句号。

还有个更省事的版本：曲一底下那个持续低音，在曲二里升到中声部去。同一个音，只是从"脚下的地基"变成"头顶的东西"。

## 10. 验收：怎么判断做对了

给朋友评审用，三条就够：

1. **盲听**。找个没玩过的人，放 30 秒，问"这是在什么地方"。
   答"水下 / 洞穴 / 地下 / 教堂 / 太空"——都对。答"森林 / 草原 / 城市 / 战场 / 海边"——重做。

2. **曲一连放三遍**。如果你开始想跳过，就是错的。它必须让人忘记它在放。

3. **两首连着听，不给解释，问"哪个在前"**。应该 100% 答对。听不出顺序，说明关系没做出来——这比任何单项缺陷都严重。

曲二单加一条：**开头 5 秒，问"你有没有抬头"**。大部分太空音乐是平着铺开的，不是往上的。

## 11. 我这边还没定的

1. **要不要一个 15 秒短版**专门卡破壳那四帧？还是直接从曲二前 40 秒切？
2. **人声要不要**？我倾向曲二要有，但只是气息不是唱。风险大的话做两个版本。
3. **轮回之后（第二轮、第三轮）曲一要不要变**？同一首加一层很轻的东西，暗示"你不是第一次来"。
4. **授权**。游戏内用、宣传片用、署名怎么写，最好一开始一句话说清，省得以后尴尬。
