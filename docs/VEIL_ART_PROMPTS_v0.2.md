## 1. 为什么换成成就图标风格

用户 2026-11-14 指出首批三张 Gemini 图「和游戏本身已生成的图画风不太符合」，并指定要**成就图标那种风格**。只读核验结论：

- 成就图标是项目里**最成熟、复用最广**的视觉语言：`assets/achievements/achv-*.png` 18 张，**512×512 PNG**（TapTap 后台硬规格，见 `docs/achievements/填报清单.md:13`）。
- **成就与挑战卡共用同一张图**：`achv-cold.png` vs `challenge-cold.webp`、`achv-abyss.png` vs `challenge-abyss.webp`，归一到 384² 后 MAE 仅 **2.4 / 2.6**（只是格式与缩放差）。⇒ 门卡本质是「卡」，用这套语言最贴，不需要另造一套。
- 首批三张属「微距材质摄影」：`L=0.08–0.11`、边缘密度 `7–20`、亮部 `1–4%`、近黑 `70–80%`、暖色 `0–1%`。成就图标（13 张主流发光细边款）均值：`L=0.33`、`S=0.69`、`edge=34.4`、亮部 `24.9%`、暖色 `16.1%`、冷色 `59.5%`、近黑 `22%`。**差 3–4 倍**，不是调几个形容词能补的。
- ⚠️ 上一版跑偏的根因在 v0.1 §3 自己：把「UI 底材要留白」写成了「画风」——微距摄影、禁止光束、自发光 <5%、80% 近黑、无主体、禁止边框。逐条删掉的恰是游戏资产最标志的特征。**不是 Gemini 跑偏，是提示词定错了画种。**

### 成就图标风格的可复用配方（从 18 张实图反推）

| 维度 | 规律 |
|---|---|
| 画幅 | **1:1 正方形**，圆角方形，四角圆角半径约 12% |
| 边框 | 约 3% 画幅宽的**青蓝发光细边**，四角略加厚；第一版挑战卡用金属铆钉框，后期 13 张统一发光细边 ⇒ **本稿统一取发光细边** |
| 构图 | **严格中心对称**，一个强符号主体占 65–80%，正面、完整、居中；不是广角场景 |
| 底色 | 深蓝黑 / 星空 / 深海水纹，四周留一点呼吸空间 |
| 光 | 主体强自发光 + 边缘辉光 + 体积光/星芒；中高亮度，亮部 20–30% |
| 色 | 青蓝主光 + **琥珀金暖光点缀**（成就图暖色像素 0.3–49%，多数 8–25%）；高饱和厚涂 |
| 密度 | 满幅细节，`edge ≈ 30–43`；小尺寸仍高辨识度 |
| 文字 | **零文字**（平台后台自动叠名称 / 灰度未解锁态） |

> `docs/achievements/成就文案_v0.1.md:117` 存有旧提示词模板（「扁平厚涂插画风 + 100 徽记」），与**实际落盘的 18 张**明显不是同一套 ⇒ 本稿以**实图**为准，不照抄那句旧模板。

## 2. 版式结论：图是门徽，卡仍是竖门

1:1 满幅高亮的成就图标**不能**当 3:4 竖卡底图（`cover` 会裁掉 25% 且压不住白字）。解法是把两件事分开：

```
卡片  aspect-ratio: 3 / 4.3   （竖门形，上一版从真图反推的形状保留）
 ├─ 上 3/4：1:1 门徽  ← 生图，零裁切，自带发光边框
 └─ 下 1/4：纯 DOM 文字带（深蓝底 + 1px 分割线）
             路径名 / 得到 / 付出 / 状态 / 第 K 重 / 帷幕点，全走 i18n
```

四条连带收益：

1. **「图要留白」改成「卡要留白」** —— 提示词里可彻底删掉安全区约束，这正是上轮画风跑偏的源头。
2. 门卡**不再另加 CSS 边框**：徽章自带发光细边即视觉边界，避免「框中框」（game-slop-purge 的同一信息不重复显示）。
3. 状态层仍全部 CSS：未选 / 选中 / 封缄 / 昼主题 / reduce-motion / 390px，不为状态多出一张图。
4. **首批三张暗材质图不浪费**：改作**封缄遮罩**盖在门徽上（近黑 70–80% 正好压住高亮徽章），三种材质对应三种封法：插槽金属→已铆封、织物→已消散、岩壳→已冰封。这正是「掀幕前只有材质、掀幕后露出文明图景」的双层叙事。

## 3. 风格锚 v0.2（每段提示词开头原样复制）

```
【风格锚 · 每段必须原样保留】
用途：游戏成就图标 / 飞升门徽，1024×1024 正方形，最终缩到 512×512 显示，小尺寸下必须一眼可辨。
画风：与上传参考图完全同款的高饱和厚涂数字绘景 + 发光徽章式图标；painterly fantasy concept art，笔触厚实、细节密集、中高亮度。不是微距摄影、不是抽象材质板、不是扁平矢量、不是 3D 塑料渲染、不是广角风景。
边框：圆角方形，约 3% 画幅宽的青蓝色发光细边，四角略加厚发光；这是装饰性徽章边框，画面内不要再出现任何框、面板、按钮或 UI 组件。
构图：严格中心对称，一个强符号主体占画幅 65~80%，居中、正面、完整不裁切；四周是深蓝星空或深海水纹，留少量呼吸空间；不要地平线、不要多个分散主体、不要人物特写。
色彩：深蓝黑 #070d18 基底 + 青蓝 #66d3f8 主光 + 琥珀金 #ffb84d 暖光点缀（暖色面积约 10~20%）；高饱和、中高亮度，禁止 80% 近黑、禁止低对比灰蒙。
光：主体自发光 + 边缘辉光 + 体积光束与星芒；允许镜头光晕；亮部占 20~30%，近黑面积小于 25%。
质感：金属 / 冰晶 / 生物膜 / 织物各有真实厚度与磨损，允许发光描边与高光；不要磨皮式平滑。
一致性：与上传的参考图保持完全相同的笔触、边框样式、光位、调色、细节密度与对称构图逻辑。
禁止：任何文字、字母、数字、汉字、符号、水印、logo、UI 按钮、面板、标签；不要人物面部与具体角色立绘；不要六边形网格、粒子雨、彩虹渐变、纯色渐变背景。
```

## 5. 规格、命名与管线

| 项 | 值 | 依据 |
|---|---|---|
| 出图 | ≥1024² 1:1 | 缩到 512² 仍有细节余量 |
| 落盘 | **512×512 webp q=85 / RGB / ≤150KB** | 对齐成就图标 512² 硬规格；⚠️ PIL `quality=85` 必须是整数，写 0.85 会被截断成 0（v0.1 §10 实测） |
| 目录 | `assets/veil/veil-emblem-{veil,si,vo,bl}.webp` | 短横线命名，同 `wonders/generated-v2` |
| 引用 | `?v=1`，换图必 bump；`main.css` 的 `@import ?v=` 另算 | 项目硬纪律 |
| 显示 | 桌面卡 318px 宽 → 徽章区 318×318；390px 单列 343×343 | 512² 覆盖 ~1.5× DPR；要严格 2× 可落 768²（可选，体积翻倍） |
| 体积 | 4 张 ≈0.5MB（对比 18 张成就 PNG ≈9MB） | 对 57MB 包增量 <1% |
| 旧图 | `tmp/veil-art/*.webp` → `assets/veil/veil-seal-{si,vo,bl}.webp`，3:4 竖、q=85 | 作封缄遮罩，不重出 |

**加载**：`decoding="async"`，首屏只解码 3 张门徽，A 懒加载；图未加载时保留纯 CSS 深蓝底兜底，功能不降级。

## 6. 数值验收（不靠肉眼，全部归一到 512² 再算）

| 指标 | 成就图标基线（13 张均值 / 常见区间） | 新图验收线 | 首批三张（作废参照） |
|---|---|---|---|
| 平均亮度 L | 0.33（0.15–0.42） | **0.26–0.40** | 0.08–0.11 |
| 饱和度 S | 0.69 | ≥0.60 | 0.71–0.79（暗部发不出色） |

| 暖色像素 | 16.1%（虚境 / 破壳可低至 1%） | 硅基 / 渊血 ≥8%；虚境允许 <5% | 0–1% |
| 近黑像素 | 22% | **<28%** | 69–80% |

另三条人工验收（按项目纪律**裁切放大 2–3× 再读**）：

- [ ] 四张的发光细边粗细、圆角半径、四角加厚一眼同款（不是三套边框）
- [ ] 缩到 128×128 仍能一眼分辨三条路径（几何 / 柔散 / 有机）
- [ ] 图里零文字、零数字、零水印；封缄遮罩盖上去后条幅文字仍逐字可读

## 7. 状态层与接缝（全部 CSS，不进图）

| 状态 | 做法 |
|---|---|
| 未掀幕 / 封缄 | 门徽上盖 `veil-seal-*.webp`（opacity .78）+ 三种条幅「已铆封 / 已消散 / 已冰封」；三路径靠**文字 + 材质 + 形状**区分，不只靠颜色 |
| 选中 | 徽章区 `box-shadow` 外发光一次性（点击时触发，非逐帧）；文字带顶部 1px 分割线高亮 |
| 昼主题 | 徽章静态 `filter:brightness(.88) saturate(.92)`；文字带换昼色；**不逐帧改 filter** |
| reduce-motion | 全部动效停，选中态常驻 |
| 文字与数值 | 全在下半 DOM 文字带，走 i18n 底表；图里永不出现文字 |
| 掀幕入口 | 自然环境页按钮卡用 `veil-emblem-veil.webp`（1:1 徽记 + 下方按钮），或复用 A 作弹窗顶部徽记 |

**性能**：静态 `background-image` 只走 Composite，4 张约 0.2ms/帧；一次性解码 512² RGB ≈0.79MB/张，4 张同帧 ≈3–8ms，远低于 768×1024 那版。循环动效仍需 60fps 钳 + `document.hidden` 守卫 + 切 tab 停 CSS animation；thermal throttle 20 分钟后才显形，验收用 DevTools 录 20s + 真机挂 20 分钟。
