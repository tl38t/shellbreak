## 1. 总览：文明6 到工业时代共 43 项，我们一对一映射

文明6 从远古到工业（不含现代/原子/信息/未来）**合计 43 项**。照抄这个分布，不做"每纪元 10 项"的人为均分。

| 纪元 | 对标 Civ6 | Civ6 项数 | 我们项数 | Civ6 成本档 | 本纪元命题 |
|---|---|---|---|---|---|
| 一 · 暗流纪 | Ancient 远古 | 11 | **11** | 25 / 50 / 80 | 活下去：手动采集 → 族群自己转起来 |
| 二 · 冷焰纪 | Classical 古典 | 8 | **8** | 120 / 200 | 从部落到聚落：第一次有"光" |
| 三 · 硫泉纪 | Medieval 中古 | 7 | **7** | 300 / 390 | 材料革命：第一次得到金属 |
| 四 · 洋流纪 | Renaissance 文艺复兴 | 9 | **9** | 540 / 660 | 探索与远征：研究产出第一次爆发 |
| 五 · 破壳纪 | Industrial 工业 | 8 | **8** + 1 终局 | 805 / 925 / 1200 | 工业化 + 撞开冰壳 |
| **合计** | | **43** | **44** | | |

成本阶梯**直接取文明6 原值**，跨纪元倍率：

```
25   → 120  ×4.80
120  → 300  ×2.50
300  → 540  ×1.80
540  → 805  ×1.49
```

**这是文明6 最重要的一条隐性设计**：时代越往后，价格倍率越小（×4.8 一路降到 ×1.49），
但玩家的研究产能在同步放大——所以后期"感觉在加速"，而不是"感觉在爬坡"。这条必须抄。

同纪元内分两档也是文明6 的原结构。

### 1.1 本纪元的动力形态（对应 `EUROPA_SETTING_v0.1.md` 第 2.2 节）

| 纪元 | 动力形态 | 人类类比 | 说明 |
|---|---|---|---|
| 暗流 | **吃电势差** | 采集 | 直接采食化能合成菌毯 |
| 冷焰 | **养电势差** | 农业定居 | 主动培育菌毯；生物发光 = 第一次有"光" |
| 硫泉 | **借热** | 火 | 第一次掌握热（热液丘 300 °C 与 0 °C 海水的温差） |
| 洋流 | **借力** | 蒸汽 / 水力 | 潮汐洋流的机械能 |
| 破壳 | **造电流** | 电 / 核 | 氧化还原电堆 + 潮汐共振 → 撞开冰壳 |

**注意顺序与人类相反**：人类是"火 → 蒸汽 → 电"，这里是"热（三）→ 力（四）→ 电（五）"。

### 3.1 两个位置的重新分配（v0.2 修正）

| 项 | v0.1 | v0.2 | 原因 |
|---|---|---|---|
| Iron Working 位置 | 育光术 → 磷砂 | **采氧术 → 氧化剂** | 欧罗巴没有金属换代，"第一次拿到战略资源"的位置给了**上位燃料**（氧化剂）。这是本设定最硬的战略资源，等于文明6 的铁 |

> **氧化剂**（采氧术 = 采氧人）是能量层面的光。两者都叫光，一个是灯，一个是电——这是刻意的双关。

## 7. 机制补充：氧化剂 × 还原剂耦合（v0.2 新增）

`EUROPA_SETTING_v0.1.md` 第 4.1 节给了一条漂亮的规则：

```
产能 ∝ min(氧化剂供给, 还原剂供给) × 转化效率
```

**但这条规则单独落地会卡死游戏**，v0.2 补一个基线解决：

| 时期 | 上（氧化剂） | 下（还原剂） | 产能 |
|---|---|---|---|
| 暗流纪 | 0 | 0 | **天然渗漏 × 天然渗漏**（微量） |
| 冷焰纪（采氧术） | 采氧场工业化供给 | 天然渗漏 | 受还原剂限制，缓慢爬升 |
| 硫泉纪（深潜术） | 工业供给 | 深潜者工业供给 | **两极管接通，真正通电** |
| 破壳纪 | — | — | 潮汐能加入乘区 |

**天然渗漏**：冰壳裂隙一直在向下渗氧化剂，海底蛇纹石化带一直在向上渗 H₂ / CH₄。
这不是设定编的——欧罗巴海洋确实存在持续的化学能通量，只是量级远小于工业供给。

**设计收益**：
1. 开局不空转（min 两侧都非零，有一口微弱的电）；
2. 冷焰纪"往上爬"有明确意义（把上极从渗漏变成工业），但玩家会明显感到**卡在下极**；
3. 硫泉纪 **深潜术一解锁，整个产能曲线跳一档** —— 这是全游戏最好的一次"接通"体验；
4. 长线危机成立：`EUROPA_SETTING_v0.1.md` 第 6 节的"热液丘正在熄灭" = 下极供给缓慢下滑，
   玩家会被推着必须争夺、必须深潜、最终必须破壳。

**待 P1 实测**：渗漏基线的数值、耦合曲线是硬 min 还是软衰减。

## 8. 三处刻意偏离文明6 的地方

| # | 偏离 | 原因 |
|---|---|---|
| 1 | **结绳免费**（揭示即完成，不花研究点） | 文明6 开局就有科研产出，我们没有——研究资源要到结绳才上线。若结绳也要花研究点会死锁。**唯一一项不花研究点的科技** |
| 2 | **Eureka → 揭示，不抵扣** | 已拍板。只借条件设计，不借 50% 抵扣效果：放置游戏白送进度会削弱决策 |
| 3 | **战争线：不删，改造** | Archery / Bronze / Iron Working / Gunpowder / Ballistics / Rifling 回到军事本行（战力 / 防护 / 阵亡率），见 `WAR_TERRITORY_v0.1.md` |
