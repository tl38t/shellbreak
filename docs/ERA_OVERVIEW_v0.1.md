## 0. 一句话总纲

**五个纪元 = 一个深海文明从「捞到什么吃什么」到「撞开天壳」的完整发展史。**
分段的依据不是深度，是**底层生产方式的换代**——每段换的是文明形态，不是数字变大。

```
  采集（捡）  →  种植定居  →  材料换代  →  走出城礁  →  人力变机械
   溯光纪        珊瑚纪       沉舰纪       洋流纪       蒸汽纪
```

文明6 从远古到工业是 43 项，我们一对一映射后 44 项（多一项终局破壳引擎）。
**纪元分段、项数分布、成本档位全部照抄文明6 实测值，不自己拍。**

## 2. 纪元一 · 溯光纪（对标 Ancient 远古 · 11 项 · 25/50/80）

### 2.1 这是什么时代

**深海文明的旧石器 + 定居革命。** 族群穴居在浅礁的裂缝里，头顶的天光还照得下来。
工具是骨片、石片、草绳。全族只有一件事：从水里捞到东西吃。

这一纪元解决的不是"变强"，是**"不再手忙脚乱"**——从玩家手动点采集，过渡到族群自己转起来。
结尾那件关键的事：**结绳**。绳子打结记事 = 这个文明第一次有了"记录"，研究资源从此上线。

### 2.2 开局状态（唯一一个手动起步的纪元）

```
1 名族民 · 唯一职业「采集者」· 唯一资源「藻食」· 建筑 0 座
手动点「采集」+1 藻食 → 攒够建第一座巢窟 → 人口开始自然增长
→ 结绳随第一座巢窟揭示 → 学者与研究上线 → 科技树开机
```

前 5 分钟是纯单线生存。科技线在**玩家建完第一座巢窟之后**才启动，这是刻意的 onboarding。

## 3. 纪元二 · 珊瑚纪（对标 Classical 古典 · 8 项 · 120/200）

### 3.1 这是什么时代

**深海文明的城邦时代。** 族人不再躲在礁缝里，而是用活珊瑚垒起第一座城礁。
驯养发光藻与磷光鱼，出现潮汐历与专职阶层。人口第一次规模化。

这一纪元的核心是**"光"**。文明6 在古典时代给玩家的是**铁**（Iron Working），
那是第一次拿到战略金属；深海里对应的稀缺战略资源是**光**——磷砂。
映射的是**角色**（材料换代 + 揭示战略资源），不是字面材质。

## 4. 纪元三 · 沉舰纪（对标 Medieval 中古 · 7 项 · 300/390）

### 4.1 这是什么时代

**深海文明的材料革命。** 族人在更深的海底发现沉没的巨舰残骸——
**这是这个文明第一次拿到金属**。行会出现、纹章出现、冷锻工艺出现。

深海文明没有矿脉可挖，金属只能靠打捞沉舰。这条既是叙事上的天然转折，
也让"沉铁"这个资源自带**获取带随机性、供给有限**的性格（见第 8 节）。

**战争在这一纪元解锁**（深潜术）。潜得更深，才发现天壳下不止你一族——
敌巢出现在外缘，第三条产出线开机。

## 5. 纪元四 · 洋流纪（对标 Renaissance 文艺复兴 · 9 项 · 540/660）

### 5.1 这是什么时代

**深海文明的大航海 + 科学革命。** 族人读懂了洋流，第一次航行到远方的海沟，
测绘出外海全图。科学方法诞生，研究产出第一次爆发。

**整棵树的关键转折在这一纪元：测天**（对标 Civ6 的 Astronomy 天文学）。
文明6 的天文学是"抬头看天"，我们的**测天**是"第一次测量天壳"——
从此破壳从传说变成**可量化的工程**。这是叙事与机制第一次重合。

## 7. 纪元跨越：不占科技位的「仪式」

`DESIGN_v0.3.md` 原本给每个纪元末尾单列了一项收束科技（入海礼 / 城礁典礼 / 洋流图 / 蒸汽先声）。
**这与「44 项逐项对标文明6」冲突**——多一项就破坏对标，且「洋流图」与洋流纪 #1 科技重名。

**改为（建议）**：纪元跨越照抄文明6 原规则——**完成本纪元全部科技即进入下一纪元**，
仪式降级为**不占科技位的自动事件**：

| 触发 | 仪式 | 内容 |
|---|---|---|
| 溯光纪 11 项全完成 | **入海礼** | 一段文本 + 一次性资源赠礼（珊瑚 +100） |
| 珊瑚纪 8 项全完成 | **城礁典礼** | 一段文本 + 人口上限 +2 |
| 沉舰纪 7 项全完成 | **铁潮礼** | 一段文本 + 沉铁 +200 |
| 洋流纪 9 项全完成 | **蒸汽先声** | 一段文本 + 研究 +500 |

仪式给的是**一次性赠礼与叙事节点**，不提供科技收益——这样科技树保持 44 项纯对标，
仪式感也不丢。

| **热液能** | 热泉蒸汽 | 蒸汽 | 热泉技师 | 工业能源，终局材料之一 |
| 星屑 | 破壳后 | 二期 | — | **二期唯一入口货币** |

**设计意图**：开局只有藻食一条线，视野随科技逐步打开。
每种资源解锁前**完全不出现在 UI 上**——这是刻意的，避免开局摆一堆看不懂的数字。

## 9. 职业解锁时间线（10 种）

职业分两类：**产出型**（直接产资源）与**加成型**（抬效率）。

| 职业 | 解锁科技 | 纪元 | 类型 | 作用 |
|---|---|---|---|---|
| **采集者** | 开局唯一 | 溯光 | 产出 | → 藻食。**开局唯一职业** |
| 藻农 | 藻圃 | 溯光 | 加成 | 藻食产出 +30% |
| 珊瑚匠 | 礁凿 | 溯光 | 产出 | → 珊瑚 |
| **学者** | 结绳 | 溯光 | 产出 | → 研究。**科技树的唯一引擎** |
| 育光师 | 育光术 | 珊瑚 | 产出 | → 磷砂 |
| 打捞者 | 打捞术 | 沉舰 | 产出 | → 沉铁 |
| 锻工 | 行会 | 沉舰 | 加成 | 建筑效率 +3%/人 |
| 航海士 | 洋流图 | 洋流 | 产出 | → 深渊晶（远征） |
| 测绘师 | 测天 | 洋流 | 加成 | 研究加成、破壳测算 |
| 热泉技师 | 热泉蒸汽 | 蒸汽 | 产出 | → 热液能 |

**每开一条职业都会改一次资源取舍重心**——这是纪元推进最主要的体感来源。
（另有一条第 11 条「出征军」不是职业，是人口的一个临时去向，见 `WAR_TERRITORY_v0.1.md`。）

## 10. 深渊地图（暂定要做，P3 与战争系统一起落地）

原为待定项，现**暂定纳入**。最小方案（不做 2D 地图，做节点表，控制内容量）：

| 项 | 设计 |
|---|---|
| 形态 | **节点列表**，不是可平移的地图。深潜术解锁后外缘可见 |
| 节点数 | 12 个（比领地上限 10 多 2，让玩家有得挑） |
| 节点属性 | 名字（断鳍礁 / 三叠沟 / 灰烬热泉…）、深度带、强度修正 ±20%、**特产** |
| 特产 | 占领后给一条固定加成（如「灰烬热泉：热液能 +10%」） |
| 玩家决策 | 打哪一块 = 挑特产 + 挑软柿子（强度修正） |

**保留线性减免结构不动**：领地统一 −4% 建筑消耗照旧，特产是**额外的一层**，
不参与减免计算。这样既给空间感和选择，又不破坏「能算到头」的减免设计。

内容量评估：节点是**一张数据表**，不是引擎——P3 增加的是 12 行配置，不是一套地图系统。
