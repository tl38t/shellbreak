# α / Ω 纪元设计语言 v0.1

> 范围：第 11 纪元 α 与第 12 纪元 Ω 的界面材质、插画构图、状态表达和动效方向。
> 上位基线：根目录 `DESIGN.md`。它是颜色、排版、间距、组件和无障碍规则的唯一来源。
> 状态：α 沿用已实现的纪元皮肤；Ω 视觉皮肤已接入，纪元内容仍按项目既有规则锁定。视觉实现不代表玩法内容已开放。
> 边界：本稿只定义视觉语言，不改玩家文案、玩法、解锁条件或生产代码。

## 1. 设计契约

| 项目 | 决策 |
| --- | --- |
| 玩家任务 | 看出文明已抵达帷幕之后的何种阶段，并继续读取资源、研究、建造等常规信息 |
| 共享系统 | 延续深海游戏的深色画布、现有正文和数值排版、卡片结构、触控尺寸与响应断点；纪元皮肤只改气氛层与强调层 |
| α 概念 | **文明穿过帷幕，在旧宇宙边缘重建。** |
| Ω 概念 | **文明把宇宙边界当作可观察、可改写的对象，最后越出它。** |
| 目标感受 | α：幽微、持续、可辨认；Ω：辽阔、精确、终止感 |
| 避免 | α 被画成泛紫魔法界面；Ω 变成满屏星云、霓虹和常驻粒子；仅靠颜色表达进度；把象征图案铺进数据文字后面 |

α 的张力来自“幕还在、文明也还在”；Ω 的张力来自“边界先被理解，随后失去意义”。它们共用深海到星海的底色，但不共用同一个主图案。

## 3. α · 帷幕之后

### 核心画面

把第 11 纪元想成深海文明从一层半透明界面后继续生活：画面仍有深海的重量，帷幕只在局部被掀开，星光是新进入的线索。玩家经过大轮回后会从早期纪元再次成长，所以 α 表达“带着痕迹重建”，不表达一次性通关后的纯星空。

### 材质与构图

- 沿用根目录 `DESIGN.md` 中 α 已定的淡帷幕紫 `#E8D9FF`、幽光青 `#80DFCF` 与 `assets/ui-era/era11-veil.svg`。
- 保留深海底色和可读的实色面板；帷幕线、弧形褶皱、散光只在开放背景区域或卡片的低对比装饰层出现。
- 最有辨识度的形状是**一条不完全对称的竖向开缝**，辅以两条宽而淡的弧线。资源、按钮和卡片不套上幕布形状，也不重复细竖线。
- 物质感停留在“薄膜／玻璃质雾层”和残留的海底器物；不要把每个面板做成半透明玻璃。信息卡仍沿用现有卡片材质。
- 纪元标记可以使用 α 字形；它是阶段索引，不取代科技、建筑或资源的专属图标。

### 信息与动效

- 资源数值、建筑状态、研究名称继续遵循共用文字与对比度 token。紫青色只辅助定位当前纪元和选中状态，不取代文字、图标或边框状态。
- “帷幕进度”这类内容由专用进度图或明确的进度结构承担；不要把整页改成长期覆盖的全屏幕布。
- 掀幕是一种有起因的事件：缝线短暂扩大、散光穿过，再回到安静的常态。普通挂机期间帷幕保持静止。
- 开启 `prefers-reduced-motion` 时直接展示开启后的状态，不靠闪光、位移或渐变才能读懂结果。

## 4. Ω · 边界之外

### 核心画面

Ω 不只是“更多星星”。它把宇宙当成可测量、可编辑的结构：先看见星海边界，再改变常数，最后越过观察者所在的维度。主视觉应从**观测仪器 → 边界／孔径 → 无边界的空场**逐步减去结构，避免把终局画成又一座更大的机器。

### 材质与构图

- 共享界面继续采用深海项目的深色画布和高对比面板。Ω 皮肤已将结局样片中的冷星光 `#A6E7FF`、亮部青白 `#C4F0FF` 和暖见证光 `#FFDFB2` 接入代码 token；深空 `#020711` 与白色星核留在结局演出及插画中。日间主题将强调色换成墨色 `#3B6575`，保证浅色面板上的文字和控件边缘仍清晰。
- Ω 的主图形采用一个开放的圆／椭圆轨道、有限的透孔边界，或一条贯穿空间的轴线。几何应精确、稀疏、容易缩小识别；同心环只用于重要的观测或完成状态，不铺满每个面板。
- 星点密度集中在插画和空白区域，普通数据卡背景优先保持稳定、暗净。光晕只用于焦点或短促回馈，亮点不能淹没资源数字。
- 蓝白是常态，暖色只标记一次关键确认、文明留下的“见证点”或结局的最后光点；不加警示条纹，不把紫色帷幕带入 Ω 主场。
- Ω 标记使用 Ω 字形作为纪元索引；“无限环”或“眼睛”不做通用装饰。具体科技、建筑和奇观继续使用既有图标资产及既有图标画风。

### 信息与动效

- 若 Ω 作为普通游戏纪元呈现，资源、科技和建筑仍用相同的布局骨架；以开放轨道的局部插画、选中边缘和当前目标标出阶段，避免另造一套难以扫描的透明 HUD。
- 升维结局沿用现有样片节奏：压暗星海、星点逐批成字、完整字形短暂停留、字形消散、最后留下一个星点。这个节奏只属于一次性通关演出。
- Ω 的日常 UI 不做持续星点闪烁。需要环境动势时使用静态构图或单次轻脉冲；完成状态须同时有可见标签／形状反馈，不能只改变颜色。
- 减少动态时将演出压成可读的最终卡帧和结束标记，保留结果信息；不强迫玩家等待动画结束才能继续操作。

## 5. 两纪元的连续性与切换

| 维度 | α | Ω |
| --- | --- | --- |
| 叙事阶段 | 掀开帷幕后，在新规则下重建 | 理解并越过宇宙边界 |
| 主形状 | 中央帷幕缝、松开的弧形褶线 | 开放轨道、透孔边界、穿越轴 |
| 色彩重心 | 幽光青与淡帷幕紫 | 蓝白星光，少量暖见证光 |
| 空间密度 | 有前后层，仍保留海底残迹 | 空间更开阔，元素更少、间隔更大 |
| 动效 | 一次掀幕，随后静止 | 星点组字与归于一点只用于终局 |
| 信息骨架 | 继承现有纪元界面 | 继承同一界面骨架，不另换 HUD |

从 α 进入 Ω 时，减少帷幕曲线和层叠质地，再引入边界几何与更大的负空间。过渡的方向是“遮挡变少、结构变明确、最后趋于空”，不是突然换成明亮的星际主题。跨纪元事件可以短暂叠加两种图形，但常态皮肤不能长期混搭。
