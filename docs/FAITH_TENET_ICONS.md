# Faith Tenet Icon Assets

Faith tenet icons use a shared scalloped shell reliquary frame in ivory mother-of-pearl, antique gold, pearl accents, and midnight teal. Each asset is a transparent 128×128 PNG. The current faith mechanism offers three random tenets at cumulative run totals of 1, 1K, 1M, and 1B Faith, then lets the player adopt one from the Faith tab. The tab shows a red dot while any choice is pending; no modal is opened. Selected tenets and pending offers are saved per run.

The five military tenets are included in the offer pool. Their effect helpers are ready for the planned war system, which does not yet have action or military-production entry points to consume them.
