| 参数 | 值 | 来源 |

### 1.1 能量从哪来（NASA 官方表述）

> 欧罗巴生命的能量**不来自阳光**，而来自两条化学线在海洋里相遇：

| 极 | 位置 | 产物 | 怎么来的 |
|---|---|---|---|
| **氧化剂** | **上**（冰壳底部） | O₂、H₂O₂ | 木星辐射把表面水冰**辐解**（radiolysis），氢逃逸、氧留下；经冰壳裂隙与混沌地形的**卤水孔隙波**输送到海洋 |
| **还原剂** | **下**（海底岩石） | H₂、CH₄、H₂S | 海水与岩石反应（**蛇纹石化** serpentinization）释放 |

- 输送效率：Hesse 等（UT Austin, *ApJL*）模拟显示，混沌地形形成时，含氧卤水下渗的"孔隙波"
  能把表面 86% 的氧一路带到海洋。
- **氧化剂量级存疑**：同一研究指出，不同参数下输送量差 1 万倍；
  只有在最高估计下，欧罗巴海洋的含氧量才接近地球海洋。

### 1.2 一个必须知道的争议（可以变成设定）

2026 年 Byrne 等人（*Nature Communications*）建模认为：**欧罗巴海底可能是冷而静的**——
潮汐力不足以驱动显著的海底地质活动，**可能没有活跃的热液喷口**，因此"今天的欧罗巴海底未必养得活生命"。

> 这不是坏消息，是**送上门的叙事驱动**。见第 6 节：把它写成"还原剂正在枯竭"这个文明级危机。

## 2. 动力源：这个世界本身就是一块电池

```
     冰  壳  15–25 km      ← 正极：木星辐射制造氧化剂（O₂ / H₂O₂）
   ═══════════════════════
     海  洋  60–150 km     ← 电解质：100 km 咸水，文明活在这层里
   _______________________
     岩  石  海  底        ← 负极：蛇纹石化制造还原剂（H₂ / CH₄）
```

**氧化剂在上，还原剂在下，中间隔着一百公里海水。整个文明活在两极的电势差里。**

### 2.1 三条直接推论

| # | 推论 | 说明 |
|---|---|---|
| 1 | **这个文明没有"火"** | 点火要三样：自由氧 + 燃料 + 点燃温度。欧罗巴没有木质燃料，氧化剂浓度可能极低，且水下点不着。人类文明的起点（火）在这里**根本不存在** |
| 2 | **他们的"第一把火"是"电"** | 第一次让电子走外电路（氧化还原电堆）= 人类第一次点火。既是火，也是电，两件事在这里是同一件事 |
| 3 | **他们的太阳是木星** | 表面辐射数 Sv/天 = 致命；但正是这些辐射在冰壳上制造了深海赖以为生的氧化剂。**杀死表面一切的东西，正是深海所有能量的源头** |

第 3 条是整个设定的诗学核心：**辐射 = 他们的阳光**。破壳之后抬头看见木星（见第 7 节），
这一幕的情感重量就来自这里。

### 2.2 动力演进五段（对标人类的 火→蒸汽→电→核）

| 纪元 | 动力形态 | 人类类比 | 机制 |
|---|---|---|---|
| 一 | **吃电势差** | 采集 | 直接采食化能合成菌毯（生命层面的能量利用） |
| 二 | **养电势差** | 农业定居 | 主动培育菌毯；生物发光 = 第一次有"光" |
| 三 | **借热** | 火 | 第一次掌握"热"——热液丘 300 °C+ 与 0 °C 海水的温差 |
| 四 | **借力** | 蒸汽 / 水力 | 潮汐洋流的机械能 |
| 五 | **造电流** | 电 / 核 | 氧化还原电堆 + 潮汐共振，工业级能量 → 破壳 |

**注意顺序与人类相反**：人类是"火 → 蒸汽 → 电"，欧罗巴是"热（三）→ 力（四）→ 电（五）"。
因为他们最早接触的能量形式就是化学梯度，"热"反而是后来才在热液丘上发现的稀罕东西。

## 4. 资源链（欧罗巴版，7 种）

| 资源 | 解锁科技 | 纪元 | 产出职业 | 是什么 | 归零后果 |
|---|---|---|---|---|---|
| **菌毯** mat | 开局 | 暗流 | 采集者 / 菌农 | 化能合成菌席，唯一的食物与基础材料 | 人口开始饿死 |
| **壳礁** shell | 冰凿 | 暗流 | 壳匠 | 生物矿化礁体（碳酸钙 / 硅质骨针），建材 | 无法扩张 |

| **还原剂** reductant | 深潜术 | 洋流 | 深潜者 | H₂ / CH₄，取自海底蛇纹石化带 | 氧化剂空烧，产能熄火 |
| **潮汐能** tidal | 潮汐机 | 破壳 | 潮汐技师 | 潮汐形变与洋流的机械能 | 破壳引擎造不了 |
| 星屑 stardust | 破壳后 | 二期 | — | 二期唯一入口货币 | — |

### 4.1 关键机制：氧化剂与还原剂是一对

**两者必须同时有，才能产能。** 只有氧化剂没有还原剂（或反过来）= 电子无处可去 = 零产出。

这给了游戏一个天然的双资源耦合：

```
产能 ∝ min(氧化剂供给, 还原剂供给) × 转化效率
```

玩家不能只堆一条线——**必须同时经营"上"（冰壳）和"下"（海底）**。
这是欧罗巴舞台独有的、原地球深海设定给不出来的机制。

人口零和取舍因此有了**空间上的实感**，不只是数字分配。

## 6. 领地重定义：热液丘（不是随机礁盘）

原 `WAR_TERRITORY_v0.1.md` 里领地是抽象的"礁盘 / 海沟"。欧罗巴版有更硬的答案：

| 项 | 设计 |
|---|---|
| 领地 = | **热液丘**（hydrothermal vent field），每座都是还原剂 + 硫铁的产地 |
| 为什么值得争 | 能量便宜 → 建造便宜。逻辑自洽地撑起"建筑消耗 −4%/块"这条收益 |
| 稀缺性 | **海底可能是冷而静的**（Byrne 2026）⇒ 活跃热液丘**极少**，每一座都是必争之地 |
| 敌方强度 | `20 × 1.35^已占领地数`（不变） |
| 深渊地图 | 12 个节点 = 12 座候选热液丘（暂定要做，方案不变） |

**把科学争议变成叙事驱动**：
"活跃热液丘正在一个个熄灭" = 还原剂供给持续下滑的长期危机。
它解释了为什么必须争夺、为什么必须深潜、以及**为什么最终一定要破壳出去**。

## 7. 破壳之后：抬头看见木星（终局画面）

破壳不是"打通了"，是**第一次看见天空**。

| 项 | 值 |
|---|---|
| 木星在欧罗巴天空的角直径 | **11.89°**（自算：R=69,911 km，d=671,100 km） |
| 相当于地球满月直径的 | **22.9 倍** |
| 相当于满月面积的 | **523 倍** |

冰下文明从没见过"天"。他们的"天"一直是头顶那面 15–25 km 厚的冰。
破壳引擎撞开冰壳的那一刻，抬头是**占满四分之一天空的木星**，以及肉眼可见的辐射辉光——
**那个杀了他们祖先几百万年、却也养活了他们整个文明的东西。**

这是第一幕的最后一格画面，也是二期（信息纪 / 宇宙纪 = 木星系统）的入口。
