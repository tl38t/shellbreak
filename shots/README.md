## 拍摄方法（可复现）

```bash
# 依赖：一个常驻 headless Chrome（CDP）
chrome.exe --headless=new --disable-gpu --allow-file-access-from-files \
  --remote-debugging-port=9333 --user-data-dir=%TEMP%\sbchrome --window-size=390,844 about:blank

# 注入 ai-player.js（项目自带，通过正式游戏 API 真实操作），等进度到目标再截图
node _shot_run.mjs# 页签截图
node _shot_break.mjs    # 破壳四帧
```

###踩过的坑（复用时必读）

1. **视口**：headless 有 512px 下限，必须用 CDP `Emulation.setDeviceMetricsOverride`
   精确设 390×844@2x，否则拿到的是「512 布局被裁」的假视口。
2. **滚动元素是 `window` 不是 `body`**：`body.scrollTop` 写了恒为 0，必须 `window.scrollTo`。
3. **`#modal` 就是破壳弹层本身**：清理遮罩时藏掉它会导致截图全空（stage/img 高度 0）。
4. **页签切换用 `SB.game.setTab()`**：`div[data-tab]` 的 `el.click()` 会被门禁闸拦回。
5. **破壳抓帧要等 CSS 过渡**：相位 dataset 切换后画面还有 850ms opacity 过渡，
   等相位名出现就拍会拿到上一相位 ⇒ 相邻两张像素相同。
6. **裁切用canvas `toDataURL('image/jpeg')`** 压缩，本机无 cwebp/ImageMagick/Pillow。
